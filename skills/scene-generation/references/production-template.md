# 场景制作模板

## 原画候选与确认

```text
场景／涉及剧集或场次：［名称、剧本出处］
剧情用途：［这里发生什么，人物如何进入、行动和离开］
空间：［入口、动线、关键活动区、建筑关系或地形］
关键道具：［物件、原位、尺寸线索、剧情状态］
原画提示词：［时代、材质、光源、氛围、机位和画幅］
候选：［原画文件和版本］
用户确认：［待确认／已确认的具体版本与消息依据］
```

原画存在多个候选时，记录获选文件。任何后续视图都能追溯到这张原画。

## 推导与返图提示词

```text
输出：［原画机位／反向平视／45°俯视／90°俯视，画幅］
美术参考：［确认原画文件］，沿用已确认的材质、色彩、光线和氛围。
几何参考（返图阶段）：［本视图对应的 Blender 渲染］，遵守其相机、体量、
透视、深度、物件尺寸、位置、接地关系和可见轮廓。
场景关系：［同一坐标系中的墙面、开口、家具、道具、通路与地标］。
可见性：［相机站位、朝向、俯仰；入画、遮挡和画外；剖顶时注明切面］。
补设或纠正：［推导阶段补设计的区域；返图阶段从模型反馈的改动］。
场景状态：［门窗开合、关键道具状态、光源位置；跨图保持的项目］。
```

各视图引用自己的 Blender 渲染，提示词同时说明两张参考图各自负责什么。遇到返图偏差时，记录成图中具体漂移的对象与位置。

## 核心模型记录

尺寸采用米制。物件有编号时在四图中使用同一编号。仅记录核对所需信息，交付已有清单时可直接链接。

| 内容 | 记录项                                                                                 |
| ---- | -------------------------------------------------------------------------------------- |
| 场景 | 原点、轴向、地面标高、净尺寸、结构厚度及通行关系                                       |
| 物件 | 编号、实际模型长宽高、位置和朝向、支撑或开合状态、尺寸来源（实测／实物参考／设计推定） |
| 相机 | 视图名、位置和朝向、俯仰、镜头或正交尺寸、画幅、可见性设置、对应渲染                   |
| 冲突 | 原画或派生图上的差异、受影响的剧情关系、模型选择和返图改动                             |
| 验证 | 实际渲染画面、可通行或可使用的净空、门窗和家具对应关系、未建模或无法验证的细节         |

## 最终交付记录

| 反向平视  | 派生图       | 路径              | 路径               | 对侧开口、家具、遮挡   |
