# 短剧场景生成

从剧情设计可反复使用的场景。经用户确认的原画定义场景的美术和空间意图，Blender 模型固定可核对的尺寸、位置和投影，四张修正后的原生场景图交给下游分镜和镜头制作。

## 1. 根据剧情设计原画，请用户确认

- 读相关剧情、剧本和已有视觉设定。提取场所功能、年代与环境、人物进出路线和活动区、关键道具及其剧情状态、光线与氛围。需要多次使用的核心场景，提前考虑动作和道具在同一个空间里如何成立。已有确认的设定直接引用。
- 生成一张完整的场景原画候选，以能交代关键空间和美术的主视角呈现。画面通常以场景为主体，剧情需要时用人物辅助表达空间尺度或行动关系。交付原图、版本和少量关键设计选择，请用户决定是否采用。
- **原画确认是继续的前提。** 等用户明确确认具体原画版本，再制作派生视图、开始 Blender 建模和生成修正版。用户要求调整原画时，交付新版本供再次确认。若已确认或用户本轮明确指定某原画为确认基准，记录该依据并从下一阶段继续。多个场景按各自版本的确认状态推进。

## 2. 从确认原画推导三个视图

以确认原画为参考，生成以下三张推导图。沿用同一场景的局部方位、门窗与家具编号、材质和光线。原画遮挡或画外的区域按剧情和物理关系补设，并在记录中标明。

| 视图      | 推导重点                                                                                                                     |
| --------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 反向平视  | 相机换到主视角的对侧，水平看回原空间。按实际遮挡推导可见的墙、开口、远端景物和家具背面。镜头位受物理条件限制时记录实际站位。 |
| 45 度俯视 | 相机相对水平向下俯仰约 45°。选一个能同时看到空间进深、墙面关系、道具与通路的方位。                                           |
| 90 度俯视 | 相机垂直向下，固定图上方向。通常用正投影检查平面关系。室内可采用剖顶或隐藏挡住平面的部分，另记显示方式。                     |

原画加三个派生视图组成建模输入。记录可见事实、补设区域和各图冲突的几何关系，再到模型中纠偏。反向平视用新方位推导，镜像无法重建遮挡与画外结构。

## 3. 在 Blender 建同一套米制核心场景

- 实际建立并保存可编辑的 `.blend`。统一单位、原点、轴向和地面标高。先定建筑体量、墙厚、层高、入口、门窗、柱梁和地形，再定家具、关键道具、墙面物件及其支撑、朝向和开合状态。与剧情、尺度、视野或遮挡有关的物件都进入模型，可用简单几何表达外形。
- 优先采用用户提供的实测尺寸或可靠的实物参考。其余用人体和活动净空、门窗常见尺度、家具使用关系推定合理设计值。标明实测、参考或设计推定。检查能否通行、开门、就坐、够到道具，以及楼层、地面和承托关系是否成立。由单张原画推定的尺寸属于场景设计值。
- 给同一场景设四台相机，分别对应原画机位、反向平视（水平）、45 度俯视和 90 度俯视。按原画的主要消失线、画幅和尺度参照校准主机位。记录相机位置、朝向、高度、焦距或正交尺寸，以及用到的剖顶设置。实际渲染四张几何参考，核对门窗位置、物件尺寸、通行、透视和各视图遮挡。保持物件和光源的场景位置一致。
- 发生冲突时优先保留剧情关系和用户确认的设计意图，直接完成尺寸、结构与机位的常规校正。只有校正需要改动已确认的核心布局或美术方向时，请用户决定该处改动。Blender 不可执行时交付已完成的阶段与具体阻塞，渲染和建模状态以实际产出为准。

## 4. 用对应的 Blender 渲染重新生成四张图

- 每张图使用两类依据。**确认原画**固定美术、材质、氛围和设计意图；**对应的 Blender 渲染**固定机位、体量、相对尺寸、位置、透视与遮挡。初版派生图仅在其中信息与模型相符时补充局部美术。按相同场景状态整幅重出原画、反向平视、45 度俯视和 90 度俯视。
- 将每张成图与对应的渲染及其余三张交叉比对。重点核对建筑轮廓、墙面与门窗、家具和关键道具、近远尺度、遮挡、支撑和光向。发现几何漂移时回同一个模型和可靠原图纠正，再整幅生成；四张图以布局和状态能相互对上为通过条件。
- 保留用户确认的最初原画、三张推导图、`.blend`、尺寸来源与相机清单、四张 Blender 渲染、四张最终图的完整原文件、实际提示词和复核结果。尺寸和投影是模型层的核对结果，成图记录可见一致性的核对结果。

用 [提示词、尺寸与交付记录模板](references/production-template.md) 跟踪四个阶段。
