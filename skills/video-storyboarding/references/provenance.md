# 来源与迭代记录

当前版本为 `video-storyboarding` 1.1.0，中文名“视频分镜设计”。由 Jijinglong 按用户要求重命名并整理内容，基于第三方 FilmPromptDirector 1.0.0，不将原始材料署名为 Jijinglong 原创，不另行指定原包未声明的许可。

原始包为用户于2026-11-17提供的 `filmpromptdirector-1.0.0.zip`，14个文件、174,884字节，SHA-256：

```text
0ea430af8eb32b469b34b1adf7b78e5ba9183044046c09dd11397d29654cfbc8
```

原包未附作者、上游仓库地址或许可文件。完整原文已保留在[1.0.0来源提交](https://github.com/jijinglong/skills/tree/d814cbdebf3b1c5de648de74cc6c1453caa61bda/skills/FilmPromptDirector)，与当前维护版区分。当前版已修改内容，不再承诺与原包逐字节一致。

## 1.1.0 的主要变化

| 原有问题                                         | 调整                                                                     |
| ------------------------------------------------ | ------------------------------------------------------------------------ |
| 大写驼峰名称，入口正文673行且重复模板较多        | 改为小写连字符名称与明确中文显示名；入口集中核心方法，详例与参考按需读取 |
| 全部任务默认完整走流程，多阶段与自动文件输出交错 | 按现有材料与本次授权选择入口；局部查询直接回答，制作包按用户要求保存     |
| 摄影镜头、生成任务与剪辑段混用                   | 明确四层单位，生成时长不套在每个摄影镜头上                               |
| 全局禁止物体移动与故事动作冲突                   | 约束具体非动作对象和生效阶段，保留剧情要求的移动、交接与变化             |
| 必写眨眼、竖屏双人禁令、动作中间切、固定百分比等 | 改成取景、叙事和表演条件下的选择，不作通用模型保证或硬性审核项           |
| 未明确绑定的素材标签、固定素材数量、括号专用语法 | 以真实输入与入口映射为准，无素材不编编号；写作约定与请求字段分开         |
| “纯净版”仍包含导演分析，示例与规则不一致         | 制作说明和可复制提示词分开；重写有相同状态与素材前提的完整案例           |
| 固定剪接帧数及白模作为万能修复                   | 根据真实成片、帧率、动作和音轨逐点诊断，效果未经观看不作结论             |

保留创意发展、剧情拆分、分镜、摄影词库、素材职责、提示词、审核和多题材例子，主要适用方向仍为 Seedance 2.0。没有自动调用媒体生成服务，也没有将1.1版本当作对模型实际效果的保证。

模型部分于2026-11-17核对火山方舟官方资料，链接与参数适用边界集中在[模型与入口核对](model-notes.md)。
