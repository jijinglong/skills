# 工作流程与交付

## 按现有材料选择入口

用户给出创意时，先明确观众最终要理解或感受到什么，再发展故事。用户给出剧本、分镜或提示词时，从该材料继续，不把已经完成的步骤重新变成问卷。

原创委托允许提出新事件、对白、人物与美术方案；它们是创作内容，不冒充用户已经给定的事实。存在明确原作、既定角色或已选方案时，再按用户的保留与改写范围处理。

| 已有材料       | 先做什么                                               | 何时补问                                 |
| -------------- | ------------------------------------------------------ | ---------------------------------------- |
| 一句话创意     | 补足用途、主要事件和风格；需要时给少量有明显差异的方向 | 关键差异会改变故事或主要画面时           |
| 完整剧情       | 保留人物、事件和对白，找出场景与关系变化，划分叙事段   | 原文缺失、矛盾或用户允许改动的范围不明时 |
| 分镜           | 检查每镜的信息职责、空间和动作衔接，再转成提示词       | 关键画面或素材不足以确定时               |
| 视频提示词     | 先审核，针对问题修改，并说明实际变更                   | 修正需要改变故事事实、对白或已选方案时   |
| 术语或局部问题 | 直接解释或改写对应部分                                 | 只有答案依赖缺失条件时                   |

一个简短、已授权的任务可以连续完成多个阶段。只有当下一步取决于尚未作出的创作选择时，才停在那个选择上。用户明确要求逐步确认时遵循其节奏；不要把每个编辑步骤都变成新的审批。

## 四种不同的单位

- **叙事段**：一次事件、关系变化或情绪推进，可以包含多个镜头与生成任务。
- **摄影镜头**：两次剪切之间的画面。景别、机位、观看对象和运动由叙事决定。
- **生成段**：一次提交给模型的任务，可以计划包含一个或多个摄影镜头。可用时长属于这个层级。
- **剪辑段**：最终时间线上的素材片段。可以取一条生成结果的部分内容，也可连接多条结果。

一个 1 秒的反应镜头不等于需要独立提交一次 1 秒生成任务；也可以放在更长的多镜生成段中，或从生成结果裁取。长镜头是画面设计，视频延长是依赖已有视频的任务类型，两者不能互相代替。

## 从故事到分镜

1. 找出触发事件、人物目标、阻力、行动和后果。确定当前段必须让观众看清的变化。
2. 为每镜选择一个主要观看对象与信息职责。可以是人物反应、双方关系、手与道具的接触、环境或证据。
3. 先写景别、机位和必要运动，再写具体动作、接收反应及声音。运动写清跟随对象与终点；固定机位本身也是选择。
4. 检查取景能否容纳关键信息。手部交接需要看见相应的手和物体；背面全景不能承担眼神或眨眼细节。
5. 选择切点：动作匹配、反应切、声音先行、视线匹配、建立空间、时间跳跃等均可。写出切换要交代的信息，而非机械规定所有切点都在动作中间。
6. 根据已核实的模型与入口限制组织生成段。复杂接触、角色出入、地点或主导视角变化，以及可独立重做的关键效果，都是候选边界；不要仅按句数或固定镜数切段。

计划秒数只用于容量与节奏讨论。除非用户要求，不把自然发生的动作写成逐秒指令；即使有时间码，也要核对原文对白与动作能否完成，不保证模型逐帧执行。

## 可选分镜表

简单任务可用自然段；需要多人协作或跨段核对时再用表格。

| 镜头 | 信息职责       | 摄影与取景                   | 动作、表演与声音               | 与前后镜的衔接     | 所属生成段 |
| ---- | -------------- | ---------------------------- | ------------------------------ | ------------------ | ---------- |
| 1    | 必须看清的变化 | 景别、角度、固定或运动及终点 | 有主语的动作、必要反应、原对白 | 具体状态或切点动机 | A          |

每个生成段补充：起始状态、结束状态、参考素材职责、计划时长或待核参数。没有实际来源时不填素材编号或模型参数。

## 两种交付

**制作说明**面向创作者：需求与假设、分镜、导演意图、素材清单、生成段划分、声音和剪辑计划，以及待核能力。

**可复制提示词**面向模型：仅保留生成所需的主体、画面、动作、摄影、声音和必要连续性。不要混入费用、审核分数、素材采购建议、导演分析或“此镜用于表达……”的解释。

用户只要正文时，直接给正文并将必要的缺失条件简短说明；需要完整制作包时，两种交付都公开给用户，不把主要设计静默藏在后台。两份交付共享同一组角色名、对白和生成段 ID。

## 文件输出

遵循项目已有目录与命名。没有项目约定且用户要求保存制作包时，可用：

```text
制作说明.md
视频提示词.md
```

交付前给出实际文件链接，说明尚未确定的字段。只问术语、评审意见或一段改写时，直接在对话中回答，不自动创建项目或文件。可以读取用户指定的已有剧本和连续性资料；其他项目的作品不作为默认素材。
