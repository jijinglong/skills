# 摄影、构图与表演参考

这些是可选的创作手段。先确定观众需要看清什么，再选择摄影方式；情绪表和风格词不能替代具体场景判断。

## 景别与信息职责

| 景别           | 常见用途                                 | 取景检查                                               |
| -------------- | ---------------------------------------- | ------------------------------------------------------ |
| 大远景／远景   | 地理关系、环境规模、人物与空间的关系     | 人物可能太小，不能同时要求观众读清微表情               |
| 全景           | 全身动作、走位、双方关系与场面调度       | 确认关键手势或小道具仍可辨认                           |
| 中景           | 对话、上身动作及人物间的交接             | 手与道具是否被画面边缘或身体遮挡                       |
| 中近景／近景   | 反应、视线、克制的表演                   | 若还需看手部动作，调整机位或另给信息镜头               |
| 特写／大特写   | 人脸、证物、手部、物体细节或决定性的变化 | 对象应可辨认，前后关系已经建立，避免只剩难以理解的局部 |
| 双人／关系镜头 | 同时交代双方距离、权力、接触和反应       | 是人数与关系的构图安排，可以与不同景别组合             |
| 越肩镜头       | 保留对话双方关系，突出接收者的反应       | 前景肩部不要挡住必须看清的脸、手或证据                 |
| 主观镜头       | 让观众接近角色的感知                     | 明确是谁的视角，必要时先用视线或反应建立关系           |

同一景别可以表达多种情绪。文戏可以依靠稳定全景中的关系变化成立，特写也可用于叙事证据；不要把近景或某类运动设为所有对话的默认答案。

## 机位、轴线与构图

- **平视、俯拍、仰拍**：先看观看关系和可见信息，再考虑亲近、疏离或力量感。俯拍不必然弱化人物，仰拍也不必然表达崇高。
- **顶视、低机位、倾斜机位**：可用于空间结构、身体与环境关系或主观不稳定感。是否使用取决于场面，不按镜头总数套百分比。
- **轴线**：连续场面先建立人物左右、视线和运动方向。改变轴线时，可以通过机位移动、重新建立关系、明显的空间参照或有意的不连续让观众读懂，不机械要求所有变化都另补一个过渡镜头。
- **中心／对称**：可表达秩序、仪式、压迫或喜剧的刻板感；具体意义来自内容。
- **三分／偏置**：给人物的视线、运动或关系变化留空间。画面左或右本身没有固定的心理含义。
- **框架／遮挡／负空间**：选择哪些信息被看见、延迟看见或被隔离。遮挡不能误遮当前任务必须展示的接触点。
- **纵深／层次**：利用前、中、后景组织关系和注意力。浅景深可隔离对象，也可能让关键动作失焦；深景深可让同框信息共同成立。
- **对角线／视觉重心**：检查注意力是否落在叙事对象上。场景、服装和光线中的强对比不应无意抢走重点。

竖屏可以采用两人紧凑并排、前后排列、越肩或交替切镜。选择时先看画面宽度与遮挡，而非先套禁令；需要展示两只手与钥匙时，宁可调整人物距离和摄影高度，也不要因为“文戏”只给脸部特写。

## 镜头运动与焦点

| 方式                       | 实际画面行为                                       | 写法重点                                                   |
| -------------------------- | -------------------------------------------------- | ---------------------------------------------------------- |
| 固定机位                   | 机位保持，变化来自表演或场内运动                   | 说明观看对象和动作，不用补随机抖动                         |
| Dolly In／Out，推进／拉远  | 摄像机靠近或远离对象，空间透视随机位变化           | 起点、关注对象、终点及显露的信息                           |
| Track／Truck，跟移／横移   | 摄像机跟随对象或横向移动                           | 跟谁、相对速度与距离、要经过或揭示什么                     |
| Pan／Tilt，摇摄／俯仰摇摄  | 机位基本不变，摄像机转向                           | 起始对象、转向动机和落点；不与横移混用                     |
| Pedestal／Crane，升降      | 摄像机位置升高或降低                               | 高度变化让什么进入视野，避免只堆设备名称                   |
| Arc，弧形移动              | 围绕对象改变观看角度                               | 转到哪一侧、相对关系如何变化；不为静止人物无目的绕拍       |
| Zoom In／Out，变焦         | 机位不变，通过焦距改变取景范围                     | 与机位推进区别表达，不说变焦必然改变透视                   |
| Rack Focus，移焦／焦点转换 | 清晰焦点在不同距离对象间转移                       | 从谁转给谁、何时以及叙事原因；不是变焦                     |
| Dolly Zoom，推拉变焦       | 机位移动与相反方向的变焦配合，保持主体尺寸近似稳定 | 后退并变焦推近，可让背景相对主体显得更大；效果仍需成片核对 |
| 手持／稳定移动             | 指画面稳定性与身体运动感                           | 写出克制抖动或平稳移动的具体效果，不把器材标签当成技术保证 |

**长镜头**是相对连续、没有剪切中断的镜头，不以是否超过 30 秒定义。一个生成段里明确写了三次切镜，就不是一镜到底。

一个镜头可以有复合运动，例如跟随人物横移后停在门口。明确顺序与终点；出现多个互相争夺观看对象的动作时，应考虑重新组织镜头。

## 光线、色彩与质感

| 维度               | 描述什么                                   | 应避免的误用                               |
| ------------------ | ------------------------------------------ | ------------------------------------------ |
| 光源与方向         | 窗光、站台灯、台灯、霓虹等来自何处，照亮谁 | 只写“电影级光影”，或同场相邻镜无理由换光源 |
| 光的软硬           | 阴影边缘和明暗过渡                         | 将硬光等同紧张、柔光等同浪漫               |
| 对比与曝光         | 明暗差、观众要看清或暂时看不清的区域       | 追求高对比却把关键手部或证据完全压黑       |
| 冷暖与色彩关系     | 主色、点缀色、肤色及场景关系               | 把蓝色永久对应悲伤、红色永久对应愤怒       |
| 轮廓光与逆光       | 分离人物与背景、隐藏或显露轮廓             | 背面远景同时要求读清脸部表演               |
| 剪影、体积光与反射 | 具体可见的形状、空气感或间接观看信息       | 为每个镜头堆满效果，导致观看对象失焦       |

把照明与色彩当成叙事选择。明亮柔和的空间也能产生悬疑；固定远景也能承载强烈情绪。颗粒、低饱和、动画、手绘或写实等风格要服务作品，不为所有项目统一追加“超写实”“杜绝CG感”。

## 表演与情绪的选择

| 关系变化   | 可考虑的可见手段                                   | 不必机械采用的做法           |
| ---------- | -------------------------------------------------- | ---------------------------- |
| 犹豫后接受 | 接触前的停顿、视线在物与人之间移动、接稳后放松握持 | 每次都低头、咬唇或眨眼       |
| 警惕升级   | 接收新信息后的反应、保护关键物体、逐渐改变距离     | 一律手持抖动、倾斜机位与快切 |
| 亲近或疏离 | 共同空间的距离、话轮与反应、主动靠近或撤开         | 固定套暖光／冷光或某一景别   |
| 隐瞒与揭示 | 遮挡、延迟显露、视线差异、观众比人物多知道的信息   | 把全部秘密写成旁白或心理解释 |
| 爆发与克制 | 前后的力量、速度、停顿与反馈对比                   | 强情绪只能靠极速运动与大特写 |

复合情绪可以在时间中转变，也可以由不同人物的反应并置。给观众可读的依据，不用同时堆叠“悲喜交加、紧张、温柔、愤怒”等互不落地的词。

## 切镜与转场

- 动作匹配适合连续交接和运动，但不是唯一切点。反应切可让选择产生重量；声音先行或延后可保持场景关系；静态切与空镜可建立时间和空间。
- 镜头间用明确状态接续。上一镜已经接稳的信封，下一镜通常从接稳后继续；独立生成需要重叠动作时，标明剪辑余量和取舍，避免最终成片无意重复交接。
- 区分**淡入淡出**（明暗或透明度变化）、**叠化**（画面重叠过渡）、**失焦／模糊**（清晰度变化）、**变焦**（取景变化）和**移焦**（焦点对象变化）。需要组合时分别描述。
- 遮挡、视线、形状、运动或声音可以作为切换依据；转场首先服务叙事，不为展示技巧而增加一场无关动作。
