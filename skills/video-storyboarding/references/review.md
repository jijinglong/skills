# 审核与问题定位

审核对象是当前需求、当前材料与本次交付。区分文本中能确认的问题、模型能力待核项，以及必须看成片才能判断的效果，不用同一个“审核通过”代替三者。

## 交付前检查

| 方面         | 检查重点                                                                     |
| ------------ | ---------------------------------------------------------------------------- |
| 故事与范围   | 人物、事件、关系、原对白和用户选定风格是否保持；是否擅自新增结果或改写事实   |
| 分镜职责     | 每镜要让观众看清什么；镜头之间是否有信息、动作或情绪的推进                   |
| 取景与可达性 | 必要对象是否在画面内；身体、手部、道具能否按描述到达和接触                   |
| 连续性       | 人物方位、视线、运动方向、道具持有者、服装、损伤与光源是否接续               |
| 约束         | 开场、贯穿全段和末态是否被混写；保持规则是否否定既定动作                     |
| 素材         | 引用是否对应真实附件、正确角色与选用版本；计划素材是否被冒充为已上传素材     |
| 声音与文字   | 台词、发声者、画外声和字幕是否分清；无配乐与无声是否混淆                     |
| 生成组织     | 单次生成段是否满足已核实的入口限制；是否误把短摄影镜头的长度当成独立生成下限 |
| 提交正文     | 是否混入导演解释、审核记录、占位符或参数备注；同一规则是否重复多次           |

## 如何分级

- **需要修正**：内部矛盾、错误的主体或附件映射、丢失已确认对白、必要动作不可达、关键信息不在取景内，以及违反已核实的入口限制。
- **需要核实**：未提供的原文或真实素材、尚未确认的模型与入口能力。可以完成不依赖这些条件的部分，但不把带缺口的文字标为可直接提交。
- **创作建议**：节奏、构图、镜头运动、情绪表达等可有多种成立方案的选择。说明影响与替代办法，不能把个人偏好判作硬性失败。

审核记录用简短的“问题—位置—影响—修改”表达。修正文本错误可直接完成；若需要改变已确认的剧情、人物关系或主要方案，则指出选择点，按用户授权范围推进。用户已经授权审改相关事实时不用再重复索要同一授权。

保留有戏剧作用的动作、表演、道具变化和因果；可以合并重复或互相否定的句子，删除不可见的过量修饰。提示词长短本身不构成失败；超过入口容量或内容无法完成时，应说明依据并重组，而非任意砍掉关键细节。

## 看成片后再判断

| 现象                 | 先核对什么                                               | 可尝试的局部调整                                                     |
| -------------------- | -------------------------------------------------------- | -------------------------------------------------------------------- |
| 人物变脸或衣装漂移   | 参考身份、变体版本、素材中是否有多个可混淆对象           | 重新分配参考职责，简化歧义描述；必要时把关键身份镜头单独重做         |
| 多出人物或分身       | 同一人多角度参考是否被误解，出入场是否写清               | 明确是同一主体及哪些角色当时可见；不把所有多视图一概禁用             |
| 争抢或交接混乱       | 谁持有物体、谁施力、何时接稳与松手                       | 指明具体肢体及状态变化；调整机位，使必要接触可读                     |
| 背景跳变             | 场景参考、固定设施位置、切镜后的空间参照                 | 点名非动作背景的保持范围；保留剧情明确要求的移动和变化               |
| 节奏拖慢             | 是否反复表演同一事件，反应是否无信息，动作是否被过度拆段 | 删除重复过程或重新选择切点，保留承重与人物选择的必要停顿             |
| 接点跳动或重复       | 真实重叠内容、动作相位、帧率及音轨                       | 逐接点比较入出点；视需要调整剪辑、声音或生成段边界                   |
| 画质或光线衰减       | 源视频质量、续写次数、参考与场景是否冲突                 | 对比直接生成与延长，减少无必要的递归续写；不承诺白模转换可以修复质量 |
| 台词、口型或文字错误 | 输入正文、说话人、发音、实际音轨和字层                   | 局部重做或使用后期配音、字幕、合成，并说明实际修改范围               |

没有成片时只能提出上述风险，不能报告模型已经产生了这些错误。接点不能统一套用“前片删6帧、后片删1帧”；白模或其他运动代理仅是需要验证的参考实验，不能冒充通用修复步骤。

文本审核结束后给出：已修正的问题、仍待核实的条件、可以直接复制的正文。只整理提示词不表示已经调用模型，也不表示成片通过验收。
