# 视频提示词写法

## 先分清任务

| 任务     | 必要输入                   | 文字要说明什么                                         |
| -------- | -------------------------- | ------------------------------------------------------ |
| 文生视频 | 当前故事与画面要求         | 要生成的事件、角色和场景；没有素材就不用素材编号       |
| 参考生成 | 实际提供的图片、视频或音频 | 每份素材中借用的对象或维度，哪些内容重新生成           |
| 视频编辑 | 要编辑的原视频             | 何时、何处改变什么，以及仍需保留的部分                 |
| 视频延长 | 要延长的原视频             | 延长方向、原片衔接状态和新增事件                       |
| 组合任务 | 各类真实输入与可用入口     | 区分编辑对象和参考对象，不让同一素材承担互相矛盾的职责 |

计划长镜头不自动意味着使用延长功能；缺少原视频时，先写直接生成方案或列明待补输入。编辑、延长及参考的实际支持情况见[模型与入口核对](model-notes.md)。

## 一段提示词的组织

1. 用简短开场建立场景、时间和关键主体；有真实素材时，先说明素材与角色的对应关系。
2. 按发生顺序描述每个摄影镜头。每镜通常以“景别／角度＋固定或运动”起句，再写谁做什么、对象如何响应。
3. 保留有意义的停顿、反应和声音关系。需要切镜时明确写“切至”，连续运动则说明镜头如何跟随，不把每段文字误当成一次剪切。
4. 同场光源、主色和整体风格集中说明；后续镜头只写发生变化或影响动作可读性的部分。
5. 最后只保留当前场景必要的约束。不要在每镜复制长串“电影级、超写实、完美、无任何问题”。

自然语言是默认交付形式。`镜头1`、`镜头2` 可以用于顺序组织；字幕、音效和台词可用明确文字区分。花括号、尖括号和中文括号不是本技能规定的通用模型指令。目标应用确有专门语法时，按实际入口编译。

## 主体与素材

- 已确认角色使用固定名字或代称，避免“他、另一个人、对面的人”在多人场景中混淆。
- 实际参考只绑定可见、已核实的特征。不要从文件名猜外观，也不要在未看素材时声称已经审图。
- 一份素材可以提供身份，另一份提供服装；讲清各自职责。不要把素材中的其他人物、背景或动作一并强行带入。
- 已明确绑定后，后文持续使用角色名即可；只有存在歧义或入口要求时才重复素材引用。
- 缺少的素材写在制作清单中，用角色名继续起草，不把计划制作的“图片1”冒充已上传图片。占位符必须在最终提交前替换或移除。
- 参考数量由实际入口容量与创作需求决定，选能解决当前问题的最少必要集合，不要求每段固定凑满 4–5 份。

## 动作与表演

一般动作简洁写清；交接、争抢、承重、机关施力等易混淆动作，再明确动作主语、施力肢体、接触对象和控制权变化。先接稳再撤手，先脱离再转向，核对人物身体能否完成过程。

用可见表演承载关系：视线落点、反应时机、停顿、姿态或一句原对白。明确的心理词可作为语气或方向，但不能代替画面；画面已经表达清楚时，不重复追加意图解释。

眨眼、呼吸和微表情只在叙事需要、取景可见时指定。没有写眨眼不等于模型一定不眨眼；也不必给每个近景加同一种表情。动作戏保留其类型强度，再通过取景和分段降低混淆，不把所有动作改成慢走、抬手和点头。

## 连续性与变化的边界

约束应点名需要保持的对象和生效阶段，例如“未参与动作的站台设施保持位置连续”“乙接稳信封后，甲撤回右手”。人物行走、物体交接、开门、变形或场景切换，只要属于既定故事，就应明确发生。

不要写“所有物体位置永久不变”来处理漂移，也不要用“全程只有一个人物”覆盖后来登场的角色。每段起始状态、过程和结束状态须相互兼容，最终剪辑不应无意重复已完成事件。为动作匹配或剪辑余量保留重叠时，在制作说明中标明重叠范围及计划入出点。

## 摄影与光线

把术语转成可观察的画面行为。推进要说明向谁推进、最终看见什么；变焦与机位移动不同，移焦与变焦也不同。一个镜头可以有有序复合运动，但应先确认观看对象和主导运动，避免同时堆叠互相冲突的摄影指令。

竖屏需要重新检查两人的头、手和关键道具能否同时被看清；可以调整人物距离、前后关系或机位，也可以切镜。没有“竖屏一律禁止双人并排”的规则。

同场主光来源应连续。柔光、正面光、冷暖色与某种情绪没有一一对应关系；可以顺用或反用，最终看它是否支持当前事件。具体术语与选法见[摄影参考](cinematography.md)。

## 声音与文字

对白保留原文、说话人和顺序；不以时长不足为由擅自删改或换同音字。多音字或专名有发音风险时，单列发音备注或使用真实读音参考，改词需要符合用户授权范围。

区分人物声、环境声、音效、音乐和字幕。无背景音乐不等于静音；要求无字幕不等于删除对白。用户已经约定无配乐时保持该选择；尚未约定时，不凭空添加一条会改变情绪的配乐方案。

精确台词、Logo 或字幕可先按要求描述，但文字正确性、口型和音色仍需看真实成片；要求精确交付时，列出后期字幕、Logo 合成或配音选项，不保证仅靠提示词即可稳定达成。
