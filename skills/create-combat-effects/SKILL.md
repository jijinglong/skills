# 制作打斗特效

先找到招式真正接触的那一帧，并记录武器或手的起点、接触点、目标反应和收势。碰撞判定由游戏或演出提供，刀光的视觉宽度可以大于接触范围。用户只有动作素材时，先做个低成本预览来确定这些时刻。

| 事件 | 画面反馈 |
| --- | --- |
| 挥击 | 从手腕、武器或脚端取样轨迹，给最高速的一段加短拖尾。 |
| 命中 | 接触点闪光，粒子沿撞击方向扩散，受击姿势随后接上。需要强调重击时再加停顿和衰减震屏。 |
| 格挡 | 闪光与火花从防具或两把武器的交点发出。停顿和震屏可弱于命中。反击用自己的挥击与接触事件。 |
| 落空 | 保留挥击刀光和残影。目标保持回避动作，落空事件的停顿为零。 |

## 实现

- 将动作时间和播放时间分开。停顿期间角色和武器姿势定格，闪光、粒子和镜头按播放时间继续。连段中同一动作时刻的多个接触共享一次最长停顿。近身对打复核上一击的火花消退时间，给下一次接触留出可辨识的画面。
- 镜头震动作用于场景，界面读数保持稳定。用连续噪声和衰减包络控制振幅。粒子使用固定随机种子或图集，以便拖动时间轴后得到同一帧。
- 浏览器预览可以直接使用 [战斗时间轴模块](assets/combat-timeline.mjs)。需要接入 Canvas、配置参数或导出图集时，读 [预览与复核](references/canvas-impact.md)。
- 需要骨骼动作或二维关节轨迹时可用 `line-figure-combat-motion`。需要绘制像素风特效或复用 PixelFX 图集时可用 `create-procedural-pixel-effects`。已有项目已有合适的动画、镜头或特效运行时就沿用。

## 检查与交付

原速看完一遍，逐帧检查接触前、接触时、停顿结束和收势。隔帧跳转到同一时刻，比对人物、特效和镜头位置。分别关掉停顿、闪光、粒子和震屏，确认改动只影响对应层。交付源码或预览时，说明事件时间、锚点、默认参数和素材出处。交付图集时附帧矩形、帧时长和锚点，并在代表性背景上检查透明边缘。
