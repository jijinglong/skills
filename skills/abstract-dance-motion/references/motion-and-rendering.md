## 手工定姿态时怎么锁脚

先给每步记下接触帧、承重帧、离地帧和地面坐标。承重期间沿用同一个脚底锚点，移动骨盆后再解膝关节。另一只脚在离地后才沿弧线去下一落点。新脚接触地面后把重心移过去，旧脚卸重后再放开它。脚跟或脚尖要转动时，选其中一个作支点，绕支点转。在换重前后用慢放确认脚底没有跟着骨盆平移。

## 示例 · 15 秒 Charleston 独舞

128 BPM，32 拍，1920 × 1080，30 fps。换舞种时保留舞句结构，按素材的节奏重选动作标记。画面以深石墨为底，线条用珍珠白，少数光弧用淡金。

| 全片拍位从 0 起数 | 时间 | 动作与光 |
| --- | --- | --- |
| 0–4 | 0–1.875 秒 | 先出现细线，再画出肩臂、圆头和腿。开场切点预留一个能接正文的站姿。 |
| 4–12 | 1.875–5.625 秒 | 踏步换重心、收膝、摆踢、还原。第 10.5 拍的伸手带出第一道弧。 |
| 12–20 | 5.625–9.375 秒 | 同一舞句换边，在第 18.5 拍让另一只手带出光弧。连续保留肩、肘、髋、脚的相位关系。 |
| 20–28 | 9.375–13.125 秒 | 再交代一次摆踢动机，逐渐收短步幅，双脚站定并留出停顿。 |
| 28–32 | 13.125–15 秒 | 第 28.75 拍补脚跟重音，脚边一条弧先展平再缩成点。 |

可从 `93_03` 的源帧 48–385 取前两个八拍，第二轮镜像并交换同名关节，再用 217–429 组织收势段。源索引从 0 起计。以触地、抬膝、摆踢极值和收脚作重定时锚点，优先确保承重脚稳定。画面直接镜像时，让远近肢的明暗随换边过渡。这个例子在略侧的投影里更容易辨认手脚，其他演员与动作需要重试视角。

## 从 BVH 到线条人

[project_bvh.py](../scripts/project_bvh.py) 从标准旋转通道的 BVH 计算世界关节，选取时间窗并正交投影。先用两三个角度做小格预览，再决定构图。保留原件，并另外保存导出的关节数据及轴向、采样率和时间窗。工具依赖 NumPy，可使用已有环境或用 `uv run --with numpy` 临时运行。

```bash
python3 scripts/project_bvh.py 93_03.bvh motion.json \
  --start 48 --end 429 --fps 60 --yaw -53 --scale 16 \
  --joints Hips,Spine1,Neck1,Head,LeftArm,LeftForeArm,LeftHand,RightArm,RightForeArm,RightHand,LeftUpLeg,LeftLeg,LeftFoot,LeftToeBase,RightUpLeg,RightLeg,RightFoot,RightToeBase
```

命令从技能目录运行，输入输出路径可替换。默认以 `Hips` 稳定画面中心，按左右肩确定正面，以两脚趾的低位估计地面。非 CMU 命名可以用 `--root`、`--shoulders`、`--floor-joints` 指定实际关节。输出的 `frames` 按 `joint_names` 展平为 `(x, y)`，画布右、下为正，地面约为 `y=0`。`source_start_frame` 和 `fps` 用于把本地采样时间映回源动作。输出是渲染用轨迹，脚掌触地、掌形、转向和表演仍需在成片里复核。

手掌可做成顺着前臂的小轮廓，有张开与放松两个状态。若需要圆润线条，在运动关节附近做短范围圆角。保持肢长来自骨架或明确的关节模型。想让光弧离手继续漂移时，触发瞬间将根部固定在当时的掌端，随后沿光迹曲线收尾。

## 逐帧渲染与独立交片

Canvas 与 Web Audio 可以共用同一个秒数或拍号，`seconds = beats × 60 / bpm`。以 `frame / fps` 绘制当前帧，使用同一张事件表触发画面和音符。渲染取画布元素的全幅内容。若视口截取出现边条，切换到画布元素截图，抽查实际 MP4 的边缘和关键帧。

把意图切点转换成实际画格。例子中开场为 `[0,56)`，收场为 `[394,450)`，各 56 帧，中间是正文。声音使用相同的帧边界，必要时对片段边缘做数毫秒淡化。若片段不是从关键帧开始，逐帧精确的切法需要重新编码视频。完整片和两个独立片段分别解码验收，核对尺寸、帧率、音轨、首尾姿态及光弧与音乐起音的时间差。
