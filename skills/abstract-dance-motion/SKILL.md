# 抽象舞蹈动效

先打开随 skill 提供的[离线动作预览](assets/preview.html)，按舞种试读真人动捕。需要更多舞句时，从[舞蹈动作库](references/dance-library.md)下载完整动作包或找到上游素材。先看动作能否独立读出舞句，再用光标出少数段落重音。

## 编舞与形象

1. **先选动作。** 确认舞种及独舞或双人需求，从库里挑能看到换重心、落脚和摆臂的连续试次。核对试次、预览和下载项对应，记录来源、使用条款及拟截取范围。用户已有合适的动作文件时直接看该文件。只找库或素材时，交付库入口和对应试次。
2. **编成舞句。** 定画幅、总时长、音乐和开收场边界。用户只给一个时长时，按含开收场的完整片长组织。用一个舞句起步，再换边或调整幅度，最后给出有准备的收势。先检查支撑脚、骨盆和肩部，再安排摆臂。缺少合适动捕时用全身示范帮助定连续关键姿态，逐段预览。
3. 缩减造型与构图。可从深石墨留白、珍珠白轮廓和一次淡金强调起步。手臂要读得出肩、肘、腕和手掌。先核对腕部轨迹，再用简洁掌形延续前臂方向。前后肢遮挡不清时，优先改投影视角、叠放顺序或远侧线条明度。修某个部位时，顺带看这一整句的重心和肢体配合。
4. 将身体的准备、到位、回收和声音写入同一拍点表。以“重拍抬膝，约半拍后伸展”为例，光弧从真正伸出的手端起，在回收时淡出。小步可以只保留轮廓。结尾可用一次落脚触发收束。

## 渲染与复核

- 做短预览。原速看舞句、脚步和音乐，逐帧查漂移、弯肘、手掌方向及相邻段的连贯性。若舞步像随机换姿势，回到支撑脚与动作来源处理。
- 逐帧渲染时让时间戳决定整帧。成片在剪辑交界按画格拆出片头和片尾，保留实际衔接状态。检查三个文件的首尾帧、画幅、帧率、含声状态和播放结果。复核输出本身的全幅构图，防止浏览器截取留下边条或裁掉画布。
- 记录使用的动作来源、片段、拍点、复用方式和输出版本。用户限定只找素材或设计时，停在对应阶段。

需要制作成片时，按需读[编舞、投影和渲染](references/motion-and-rendering.md)，或在[开收场预览](assets/line-dancer-transitions.html)查看可独立调用的入场、出场。
