# TikTok 短视频创意结构

读用户的目标、受众、成片形式、时长与已有素材，写一句观众点开后应该立即看见的承诺。用开场提出具体问题，中段不断给出线索或结果，结尾兑现最早的承诺。

## 把六个原则用在分镜里

| 原则 | 创作决策 |
| --- | --- |
| 平台原生 | 用适合手机浏览的竖屏构图和可独立读懂的首帧。用短配字承接动作与信息，静音也能跟上。 |
| 借用趋势结构 | 找与题材、语言和受众相合的表演、切镜或叙事形式。把形式换成这条片自己的人物、素材与情节。用户需要当下趋势时，查发布地区和日期。 |
| 生产与构图 | 以竖屏清晰画面为基准，用目标平台的界面预览测试小字、底部字幕和右侧主体。按反馈更换开场镜头、角度或标题，在同类版本间保留可对照差异。 |
| 开场、推进、收束 | 开场尽早展示异常动作、明确利益或正在发生的冲突。中段让局势、线索或判断发生变化。剧情片给可见的结果和人物反应，广告给与内容自然衔接的行动指引。 |
| 剪辑刺激 | 在新信息出现时才用切镜、运动、字幕、转场。允许关键线索停够阅读时间，高潮前后用快慢变化区分。 |
| 声音设计 | 明确每个音效、配音、音乐或停顿所承担的情节职责。让声音与动作同拍；按用途核对音乐权利。 |

## 设计或审查一条片

1. 为开场写下「画面里有什么」和「观众此时想问什么」。先写能拍到的动作、道具或反常结果，再决定是否需要一句配字。核对封面与首镜承诺的是同一件事。
2. 按时间记录每一段的主动作、声音或配字、观众新增的信息、接下来还想知道的问题。回答一个问题后，尽快让这个答案触发下一步行动。只靠延迟答案维持的段落，补进一个可见线索、选择或后果。
3. 停在能看见结果的镜头上。先检查主悬念是否被画面解决，再选择是否留一句人物台词、一个反应或行动指引。
4. 用一次静音预览找理解障碍，再用一次有声预览核对节拍与字幕阅读。把可疑区间写成「时间、问题、具体修改、修后能看懂什么」。有实际表现数据时按相同口径看开场离开、后续掉点和结尾到达。只有设计稿时把留存判断写成待检验的假设。

例如，空椅被拖进已经坐满的合影，观众先想知道椅子给谁。两张旧照与此刻的拍摄者回答了第一个问题。角色马上架起手机倒数，于是接着要等快门拍到了什么。最后重用首镜构图，让椅子真正坐上人。
