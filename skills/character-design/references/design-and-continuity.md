# 身份设计与连续性

## 不同角色：建立可比较的身份

稳定身份、当期造型、拍摄条件分开。稳定的是脸和骨架，不是永远梳同一个髻、穿同一件衣服。烟灰、疲惫和便装不能改变下颌、鼻背与眼距。

每人的最小身份契约：

| 字段 | 内容 |
| --- | --- |
| 身份 | 现有ID、姓名、已知年龄或阶段、性别、故事事实来源 |
| 审美定位 | 主角的吸引力类型、普通配角的自然外形、剧情明确需要的粗犷或丑角特点；不因反派身份自动丑化 |
| 3个主锚点 | 可从画面直接比较的特征组合，按优先级排序 |
| 骨相 | 脸的长宽、额头、颧弓、下颌转角、下巴形状与前后位置 |
| 五官 | 眉形和眉眼距离、眼裂／眼距／眼睑、鼻根／鼻背／鼻尖、嘴宽／人中／唇形 |
| 身形 | 相对身高、肩颈、胸腰、四肢比例、筋肉与软组织体积、自然站姿 |
| 表面与毛发 | 肤色底色、年龄纹理、发际线、胡须；既有永久标记及侧别 |
| 造型列表 | 衣物层次、领袖、腰带、鞋、当期发髻、烟灰与伤态，附生效时段 |
| 重点对照 | 最易混淆的2—3人，哪些结构必须拉开 |
| 母版 | 实际文件或资产ID、选择依据、真实复核状态；未生成就为空 |

先填全角色差异表，再写逐张提示词。让最相似的人在脸长宽、眉眼关系、鼻口结构和身形中有数项清楚差别，而不只换肤色、头饰或名字。3个主锚点是生成优先级；其余细节支持整体，避免堆十几个竞争的奇观。

可选维度包括：长矩形／短五边形／菱形／下宽梯形；平短／后收／圆下巴；覆睑长眼／短圆眼／厚上睑小眼；低短圆鼻／直钝鼻／骨节鼻；宽平嘴／肉感小嘴／长人中。这是设计工具，不是给每个人都添加特殊标记。保持自然人体与项目风格，反派不自动丑化，正派不自动成为同款美人；不依赖真实演员姓名或复制知名角色的脸。

用户授权增强差异时，可以提出新的自然骨相和体态；明确标成美术设计，不伪称剧本事实。没有依据的伤疤、雀斑、纹身、异色瞳等不拿来凑差异；确有设计必要时先纳入可 review 的新身份提案，不能悄悄加进已确认角色。

## 示例：沈知雪与阿满

### 美感与肤质的共同边界

先确定“怎样好看”，再决定“怎样不同”。沈知雪是成熟、清艳而有英气，阿满是明亮、灵动而有生活气；不能把沈知雪的英气做成过长粗重的男性化骨相，也不能把阿满的市井劳作做成肤色脏暗。陆沉可以沉静俊朗、清瘦有力，不靠憔悴和粗大毛孔显得真实。

年轻角色默认皮肤细腻健康、肤色均匀有自然气色，保留轻微可信纹理即可。柔光中有清楚眼神光，面部正常曝光；不要在所有提示词里重复“粗糙、日晒、毛孔、灰黄、凹陷”。老人有年龄相称的细纹和松弛，仍不自动增加皮肤病、斑疤或全脸脏污。烟灰、血色不足、伤势仅按当前剧情局部表达，不能扩散成每张日常皮肤的默认状态。

自然皮肤不等于重度颗粒和缺乏气色；有美感也不等于蜡像磨皮、过曝漂白或每人同一张精修脸。暖麦、深肤色同样可以细腻、干净和有光泽，肤质改善不擅自改变母版肤色底色。

取美感参考时声明只控制审美气质、妆面克制程度和肤质光色；不自动复制模特身份，也不继承现代衣服、珠宝或参考背景。画风统一后，每人仍建立自己的唯一身份母版。

这是本剧的新增美术提案示范，不是其他项目的人物事实。

| 人物 | 主锚点与身形 | 当期造型 |
| --- | --- | --- |
| 沈知雪，28岁巡兵使 | 长六边形骨相、短平下巴；长直眉下横向细眼；高直窄鼻头。高挑平肩、肩臂有训练痕迹 | 深青窄袖官服、墨黑短披风、皮护腕、素银小冠 |
| 阿满，19岁面摊姑娘 | 短梨形脸、圆短下巴；短浓眉与稍宽眼距圆眼；低短鼻梁、宽圆鼻头、饱满下唇。偏小、紧凑结实 | 日常赭黄短衣与靛蓝长围裙；入坊灰蓝短衣、深褐裤、低辫髻，无围裙 |

遮住头饰和衣服仍应能读出差别。后续沈知雪换便服、阿满盘起辫子，上述骨相与比例仍保留。统一真人武侠风格、背景与光线，不互借身份图。

## 同一角色：封闭参考范围

| 用途 | 允许控制 | 不得控制 |
| --- | --- | --- |
| 身份母版 | 脸、年龄、骨架、肤色、发际线、既有标记 | 新造型衣服、临时伤态、道具、排版、背景 |
| 服装参考 | 指定衣物层次、材质、配色、配饰 | 模特的脸、年龄、体型 |
| 风格参考 | 摄影／绘制方式、材质、光色 | 人脸、设定板结构 |
| 版式参考 | 经本技能固定规则允许的结构说明 | 任何人物身份；不能覆盖固定比例 |

交给工具的每张图都写明用途。只在文字里写文件名不等于图片已传入模型。没有真实母版时，变体标为“等待身份母版”；可以先完成文字，不能声称锁脸或把旧图填成新母版。

保留身份时母版优先于代理自行补出的描述；用户明确要求重设计时，新设计优先，旧图只控制指定保留部分。多个参考冲突时选择明确主母版，不平均五官；影响结果的真实冲突才澄清。

## 不对称与左右侧

先登记人物自身左右，再写画面映射，避免仅写“左边有疤”：

| 视角 | 人物左侧标记的关系 |
| --- | --- |
| 正面 | 画面右侧 |
| 背面 | 画面左侧 |
| 人物左侧严格侧面 | 左侧近，脸朝画面左；右侧标记通常被挡住 |
| 人物右侧严格侧面 | 左侧远，脸朝画面右；左侧标记通常被挡住 |
| 三分之四侧脸 | 先声明展示人物哪一侧，远侧标记不能穿透出现 |

表格针对中性直立、正常成像，不镜像源图。正文同时写“人物自身左前臂，正面位于画面右侧”这类关系。侧面真正90度，鼻、胸、脚尖方向一致；三分之四视角只用于右下近景。

伤疤、痣、耳饰、衣襟、武器佩挂和持物手逐项核对；未记侧别先看原图，不猜。衣服遮住伤疤是正确状态，不要求每格露出。需要握持时检查手物接触，不为设定板擅自换手。辅助道具不遮脸、手臂和服装结构。

## 可视验收

- 不同角色：中性正脸等尺寸并排，去掉服装、发饰提示后核对3个锚点；再比较侧脸额鼻唇颏轮廓。灰度或轮廓副本只供检查，不覆盖原图。
- 同人变体：对照母版逐项看脸长宽、眉眼关系、鼻尖、唇形、下巴、年龄与体型，不能用“气质接近”代替身份。
- 板内一致性：五个视图同人同造型，发式、领口、衣襟、鞋、标记对应；侧面不偷换成三分之四正面。
- 发型自然程度：核对发根、发束走向与耳前鬓角，避免成排透明细线、悬空发丝或不自然地贴过下颌颈部。束发角色需要耳前清爽时，使用自然贴合的短鬓角、长侧发收入耳后，保留少量短绒发；设定明确要求披发或长鬓发时按其真实重力与结构处理，不一律删去。用户已认可面孔而只指出头发问题时，只修正发型自然度，不能顺带重设计五官。
- 正侧美感单独验收：正脸漂亮不能代替侧脸通过。对照同一身份的鼻根高度、鼻背鼻尖、鼻底至唇至下巴关系、颧颊体积和下颌轮廓，区别正常透视变化与五官重新设计。全身小脸细节不清时查看原图；右侧大近景也不一致就退回母版，不能因总体像同龄同风格的人而判通过。用户只认可某个角度时，参考范围明确限制到该角度，其余失败视图不能混作身份依据。
- 相对身高记入契约，等高排版不代表全剧同高；无需声称所有人只凭黑影都能辨认。

契约、种子、参考强度都不能证明图像一致。只有查看实际结果才能写“本图身份通过”，仍不承诺后续零漂移。

## 正脸可用、侧脸失败时

侧脸可以单独设计美感，但它必须是同一人的三维结构：眼眶深浅、眉弓、面中体积、鼻根鼻背鼻尖、鼻底至唇至下巴的衔接共同成立。不要只把脸压短或加宽来修美感，也不要为立体感单独拔高鼻梁或削尖下巴。姿态保持中立，光线有轻柔体积塑形和足够补光；完全压平光影也会让面部显扁。

当用户只认可板内某张正脸，而整板引用继续带回失败侧脸时，先用当前图像工具重建独立的认可角度身份参考，核对其是否保留原面孔；再制作大幅正面／90度侧面／三分之四侧面的中间身份校准素材。中间素材用于把正侧五官与审美核对清楚，不能冒充最终约定版式交付。三角度身份稳定后再投到完整五视图板。只将实际传入的文件记为生成参考，浏览过的外部照片不能写成实际参考输入。
