# 固定版式与提示词

## 尺寸能力

目标为2560×1440像素、16:9，写进完整提示词；角色和道具与剧集9:16等成片比例无关。不是1920×1080。

- 工具支持精确宽高：核对当前真实schema，只用支持的参数指定目标，生成后读取文件真实宽高。
- 内置工具没有尺寸参数：不编造`size`、不假定提示词能强制像素。当前用户已选择继续内置工具并接受原始尺寸，沿用该选择，保留原始字节。历史返回1672×941是观察值，不是未来保证，也不取代目标。
- 用户后来要求硬性交付2560×1440：先核对能否满足；不能满足时说明差距并给出可执行选择。切换提供商或缩放补边需相应授权，不能自行改用付费服务。

分别记录目标与实际宽高。原生像素取整可能产生微小比例误差，原样报告，不能把近似16:9说成数学上的精确16:9。像素、布局和身份是三个独立验收项。

## 唯一版式

| 区域 | 角色 | 道具（同批请求才启用） |
| --- | --- | --- |
| 左区宽2/3 | 从左到右：正面、严格90度侧面、背面全身；等比例、足底基线齐、头顶鞋底完整 | 同一物件正面、侧面、背面；等比例、底部基线齐、完整不裁切 |
| 右上：宽1/3、高1/2 | 同人正面头肩近景 | 点名的第一处结构细节 |
| 右下：宽1/3、高1/2 | 同人三分之四侧面头肩近景 | 点名的另一处结构细节 |

角色近景放大尺度一致，发顶、发髻、脸、下巴与少量肩颈完整，表情状态一致。每张只有一个身份、一套造型，不是三个工匠放左边。道具必须分别写清“右上箱盖铰链、右下正面锁扣”等部位，不能只写“细节图”，不能用打开／闭合或完整／破损对照填格。

仅两条分割线：竖线位于宽2/3、贯穿全高；横线位于高1/2，仅从竖线延伸到右缘。均为最终原始文件上的1像素宽、纯白#FFFFFF、不透明直实线，横竖等粗。边界取最近整数坐标；2560宽的2/3不是整数，不能因此增粗线条。

左区不加列间线，背景连续。无第三个右侧小格、角落插图、表情网格、色卡、文字标签、箭头、尺寸线、外框或卡片式宽留白。统一浅暖灰无缝背景、中性均匀柔光；正常留边，不因“无宽留白”裁头裁脚。

像素线宽和位置是要求，仍须查看原图。预览缩小的线宽不是证据，未测量时写“目视近似／未测量”，不报精确验证通过。

## 提示词组装

顺序：身份与3个主锚点 → 当前唯一造型／状态 → 参考控制范围 → 画幅版式 → 风格光材质 → 保持与排除项。沿用项目确定的语言，本用户现有项目为中文。流程说明、待定字段和路径放正文外，不让模型画出模板字段。

母版是创建身份，换装是继承身份。换装正文重复关键锚点，工具实际提供该人母版，不能只写“同一个人”。每条交付正文完整展开，不让下游寻找“参考上文”；可以脚本拼公共段，但发给工具的必须是全文。
