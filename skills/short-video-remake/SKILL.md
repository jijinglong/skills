# 短视频重拍

先从现有作品接续。读取项目规则和作品入口，找出参考源、已确认的重拍方向、采用的素材版本、时间轴以及 Spark 项目。仅执行用户这次要求的阶段。确认作品、画幅、声音用途和交付位置，沿用已定选择，需要决策时先完成能独立开展的工作。

在 Beat 项目使用 `works/<slug>/`。原件放 `sources/`，可复核的拆解放 `analysis/`，剧本、生成提示词和生产素材放 `production/`，已选定的交付放 `exports/`，临时文件放 `scratch/`。其他项目沿用其目录约定。用稳定的场景和镜头编号关联素材、时码、剧本和 Spark，版本迭代后更新入口和采用版本。

## 1. 拆解参考视频

- 用 FFprobe 或等效工具核对画幅、时长、帧率、时间基准和音轨。保留原视频、独立音频和字幕原件；优先复用已有可信的拆解。可用已安装的 `rea-video` 辅助逐镜观察。
- 用抽帧或接触表定位切点，再查看切点前后画面。逐镜记录入出时码、场景、景别、机位、动作、道具和转场。区分观察到的内容与对制作方式的判断，无法确认的部分标记待核。
- 为声音单独记录进入点、原语对白或歌词、关键词与动作的对应。优先核对已有字幕和原音。字幕开头、音乐拍点、实际发声与画面切点分别记录；有条件时试听确认，不凭字幕认定每个字的落点。
- 遇到 `Audio input is not available.`，确认当前模型和调用方式是否支持音频。若不支持，从请求里移除音频附件，包括重试时带入的旧附件。用本地工具提取时长和波形，结合现有字幕、文字转写或支持音频的工具继续。未能核实的发声细节保留待核。

交付可回看原片的时间轴和重拍取舍。时间轴上的入出点保留原始精度，生成工具若只能用整数秒，在实际提交时另填覆盖目标区间的时长。

## 2. 挑选参考素材

- 先固定用户已选的人物身份参考，例如 Loop 中已指定的脸。按实际可用的素材库或检索接口确认图片可打开，记录路径或素材 ID。只有同一角色的镜头共用这张身份参考。
- 根据场景挑选服装、发型、妆容、姿势和道具。把服装和姿势分开选，按用户允许的范围改变发型和妆容。找不到合适素材时，说明缺口并按制作要求设计新参考。
- 给每项参考写明职责，例如锁脸、服装、场景构图、动作起点或动作目标。姿势图已经呈现动作终点时，把它用作动作参考，另选适合起手的首帧。对口型特写需看清嘴部，手和道具的走位也要避开遮挡。

## 3. 生成新场景和角色图

- 先定每个场景的地点、光线、构图和可表演空间。需要单独的场景图和人物出场图时，优先选定无人物的场景图，再用选定场景、统一的人脸和本场造型生成角色在景图。按镜头用途决定需要全身、半身还是特写。
- 按用户确认的服务、模型、质量与尺寸执行。用户指定 ChatGPT 的 API 时，用已配置的 OpenAI 图片 API，在本地加载项目凭据。Beat 使用 `uv run --env-file .env`。核验当前模型和接口支持的尺寸，再核对成品的实际像素和比例。`1024 × 1536` 是 `2:3`，`1152 × 2048` 和 `2160 × 3840` 是 `9:16`。
- 逐图核验数量、画幅、同一人、造型、场景与预定动作阶段。保留原图。下游有格式或请求体限制时，从原图另做适配版，复核视觉质量、实际字节数和整次传输后的体积。
- 将采用的素材、实际使用的模型和参数、最终提示词及参考关系写回作品。跳过已经符合要求的生成，避免重复花费。

## 4. 创建剧本和分镜

- 以用户已有剧本为源稿；从参考重拍时，按已确认的方向写明场景、动作、表演和原语台词或歌词。音乐驱动视频用同一条原音作为时间基准，把换景、嘴型可见的演唱和动作卡点落到具体歌词或时段。区分画面拍点、发声起止和过场，保留连续音轨。对白类作品记录说话人和原句。
- 让场景、角色和剧本能对应。每个场景写地点、时段、动作与声音；同一人物建一份身份设定，各场的衣服、发型和妆容做造型变体。地点需要多角度时记录相关视图。为分镜补上参考图、发声对象、道具、机位与动作的起止状态。
- 根据目标模型选择生成段。一条能容纳全部镜头、音频和时长的任务，可在同一提示词里用相对时码写切镜、演员动作和参考图。使用单人物对口型或有换景限制的工具时按必要边界分段。记录每段原音入出点、目标剪辑时长、提交时长与多余部分的裁剪位置。保留用户要求的转场，未指定时根据画面与乐句选择。
- 对口型依赖所选工具的音频驱动能力和实际输出。提示词写清语言、录音的职责和关键动作；有生成结果后再听看元音、闭口音、换句和跨片段切点，报告实际对齐情况。

## 5. 同步 Spark

用户要同步时，按 [Spark 同步与复核](references/spark-sync.md) 操作。先就地匹配已有项目，再根据授权创建或更新。同步剧本、角色及造型、场景及视图、分镜、提示词和本次使用的参考媒体。回读项目并核对范围、引用、时长和实际送交模型的正文。提交付费生成按用户对生成的授权执行。

收尾时标明处理到的阶段和采用版本，附上作品入口、关键交付物以及已同步的 Spark 页面。分别记录完成的同步和已实际生成的媒体，写明需要用户核对的时码或素材缺口。
