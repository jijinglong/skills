## 1 文字生成

Seedance 2.0 系列模型支持生成常用文字。模型能根据情境**自动匹配**合适的风格与颜色，也支持在提示词中**指定**文字的颜色、风格、出现方式、出现时机、出现位置。

### 编写要求
- 优先使用**常用字**，避免**生僻字**与**特殊符号**
- 当前支持广告语、字幕、气泡等场景

### 广告语（Slogan）模板

```
「文字内容」+「出现时机」+「出现位置」+「出现方式」，「文字特征（颜色、风格）」
```

**示例**：画面中部显示文字"快乐尽在 Seedance"

### 字幕模板

```
画面底部出现字幕，字幕内容为"……"，字幕需与音频节奏完全同步。
```

### 气泡台词模板

```
「角色」说："……"，角色说话时周围出现气泡，气泡里写着台词。
```

## 2 视频延长 vs 分段拼接

两种策略适用于不同场景：

| 策略 | 适用场景 | 特点 |
|---|---|---|
| **连续长镜头（视频延长）** | 单一场景内的"文戏"：长对话、情绪递进、单一路径移动 | 沉浸式、连贯的一镜到底效果 |
| **场景/动作转折（分段拼接）** | 剧情转折或复杂、快速的"武戏"：追逐、打斗、蒙太奇等 | 通过独立生成片段再剪辑组合，保证节奏与视觉冲击力 |

### 实际制作建议
通常结合两种方式：先用延长生成连贯对话，再拼接空镜或转场片段，兼顾沉浸感与节奏变化。

### 策略判定规则

| 分镜特征 | 推荐策略 |
|---|---|
| 同一场景、同一组人物、连续对话/动作 | 视频延长（长镜头） |
| 场景切换、视角剧变、时间跳跃 | 分段拼接 |
| 剧烈动作（追逐/打斗/爆炸） | 分段拼接 |
| 情绪递进、缓慢渲染 | 视频延长（长镜头） |
| 蒙太奇式快剪 | 分段拼接 |

## 3 素材配置策略

### 3.1 四种功能角色

通常把素材分成四种"功能角色"：

1. **角色锚定**：锁定角色外观
2. **场景定调**：锁定环境与风格
3. **运镜参考**：锁定镜头语言与动作节奏
4. **节奏氛围**：用音频控制情绪、音色

### 3.2 推荐配置

总计 4-5 个素材：
- 角色图 1-2 张（面部特写/全身）
- 场景图 1 张
- 运镜视频 1 段
- 音频 1 段

> ⚠️ 不建议用满素材上限，过多素材会导致模型难以判断特征优先级，易出现风格冲突、主体识别模糊、生成效果偏离预期等问题。

### 3.3 素材上传顺序

越需要**精准参考**的素材，放在提示词中**越靠前**的位置。

推荐顺序：
1. 人脸特写图（大头照）— 最重要，放最前
2. 全身/半身参考图
3. 场景参考图
4. 运镜参考视频
5. 音频素材

### 3.4 角色锚定的最佳实践

- 准备**人脸特写图**（大头照，仅保留面部，无表情最佳，减少肩颈、背景干扰）
- 提示词中明确：`<主体1>的面部特征参考图片1（大头照），妆造参考图片2（全身照）`
- 人物参考使用大头照 + 全身照即可，**不建议使用人物多视图**
- 多视图素材包含同一人物不同角度，模型易将其识别为多个不同主体

### 3.5 素材准备清单模板

在分镜拆解完成后，应自动汇总所需素材清单：

```
📦 素材准备清单
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎭 角色锚定
  • @图片1：{角色名} 面部特写（大头照）
  • @图片2：{角色名} 全身照

🏞️ 场景定调
  • @图片3：{场景描述} 参考图

🎬 运镜参考
```

## 4 视频延长衔接指导

当存在多段视频需要拼接时，后期剪辑需注意帧对齐：

### 衔接处理步骤

1. 将待拼接的视频导入剪映或其他专业视频剪辑软件
2. 在第一个衔接处，将**前一段视频的末尾删减 6 帧**
3. 同时，将**后一段视频的开头删减 1 帧**
4. 对所有的拼接点重复以上操作
5. 导出并检查拼接后视频的流畅度

### 最佳实践

视频帧对齐后仍可能存在细微跳变，建议：
- 在续写生成视频时以**转场切镜的时刻结尾**
- 下一段视频以结尾切镜后的**新场景为起始**
