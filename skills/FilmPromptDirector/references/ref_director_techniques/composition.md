# 构图法则与视觉设计

## 经典构图法则

### 三分法则 (Rule of Thirds)
- **描述**：将画面分为 3×3 网格，重要元素放在交叉点或线上
- **情绪**：平衡、自然、舒适
- **用途**：通用构图，避免画面呆板
- **示例**：角色眼睛放在上三分之一线，地平线放在上或下三分之一线

### 黄金分割 (Golden Ratio / Fibonacci Spiral)
- **描述**：按 1:1.618 比例或螺旋线构图
- **情绪**：和谐、优雅、艺术感
- **用途**：追求美学极致的画面
- **示例**：螺旋中心放置主体，曲线引导视线

### 中心构图 (Center Framing)
- **描述**：主体位于画面正中心
- **情绪**：对称、稳定、权威、超现实
- **用途**：强调主体、韦斯·安德森风格、宗教意象
- **示例**：《布达佩斯大饭店》对称构图

### 对称构图 (Symmetry)
- **描述**：画面左右或上下镜像对称
- **情绪**：秩序、完美、压抑、超现实
- **用途**：建筑、宗教场景、表现控制感
- **示例**：走廊、宫殿、宗教建筑

### 引导线构图 (Leading Lines)
- **描述**：利用线条引导视线到主体
- **情绪**：方向感、深度、聚焦
- **用途**：道路、走廊、栏杆、光线
- **示例**：铁轨延伸、走廊透视、光束指向

### 框架式构图 (Frame within Frame)
- **描述**：用前景物体形成画框包围主体
- **情绪**：聚焦、窥视、层次、隔离
- **用途**：门窗、洞口、树枝、镜子
- **示例**：透过窗户拍摄、门框中的角色

### 对角线构图 (Diagonal Lines)
- **描述**：主体或线条沿对角线分布
- **情绪**：动态、紧张、不稳定、能量
- **用途**：动作场景、表现冲突
- **示例**：楼梯、倾斜的身体、武器指向

### 三角形构图 (Triangular Composition)
- **描述**：三个元素形成三角形
- **情绪**：稳定（正三角）或紧张（倒三角）
- **用途**：三人对话、权力关系
- **示例**：三人围坐、金字塔式站位

### L 型构图 (L-Shape)
- **描述**：主体形成 L 形布局
- **情绪**：稳定、沉思、安静
- **用途**：坐姿人物、静物
- **示例**：人物坐着，身体和腿形成 L 形

### 填充构图 (Fill the Frame)
- **描述**：主体填满整个画面
- **情绪**：压迫、亲密、无逃避
- **用途**：特写、表现情绪强度
- **示例**：面部特写、无背景留白

## 画面层次设计

### 前景 (Foreground)
- **作用**：增加深度、提供信息、创造框架
- **元素**：栏杆、植物、家具、人物局部
- **技巧**：虚化前景创造景深、清晰前景创造框架

### 中景 (Midground)
- **作用**：主要叙事区域、主体位置
- **元素**：主要角色、关键动作
- **技巧**：保持清晰、控制视觉重心

### 背景 (Background)
- **作用**：建立环境、提供语境、烘托氛围
- **元素**：建筑、风景、人群、天空
- **技巧**：虚化突出主体、清晰展示环境

### 层次技巧
1. **深焦 (Deep Focus)**：前景中景背景都清晰
   - 情绪：客观、信息量大、选择权给观众
   - 示例：《公民凯恩》

2. **浅焦 (Shallow Focus)**：仅主体清晰，前后景虚化
   - 情绪：聚焦、亲密、主观
   - 示例：对话特写

3. **变焦移焦 (Rack Focus)**：焦点从一个物体转移到另一个
   - 情绪：注意力转移、揭示关系
   - 示例：从 A 角色转移到 B 角色

## 视觉重心与平衡

### 视觉重心位置
- **中心**：稳定、正式、权威
- **偏左**：自然（阅读习惯从左到右）
- **偏右**：不安、期待（违反阅读习惯）
- **上方**：轻盈、自由
- **下方**：沉重、稳定

### 视觉平衡
1. **对称平衡**：左右元素镜像或等重
   - 情绪：稳定、正式、完美

2. **不对称平衡**：不同元素通过大小、颜色、位置达到平衡
   - 情绪：动态、自然、有趣

3. **不平衡**：刻意制造失衡
   - 情绪：紧张、不安、即将变化

### 视觉重量因素
- **大小**：大的更重
- **颜色**：暖色、饱和色更重
- **对比**：高对比更重
- **位置**：下方、右侧更重
- **复杂度**：复杂纹理更重
- **人脸**：人脸吸引注意力

## 空间与透视

### 一点透视
- **描述**：所有线条汇聚于一个消失点
- **情绪**：聚焦、纵深、引导
- **用途**：走廊、道路、隧道

### 两点透视
- **描述**：两个消失点
- **情绪**：立体、真实
- **用途**：建筑外角、室内角落

### 三点透视
- **描述**：三个消失点（含垂直方向）
- **情绪**：夸张、戏剧性、高大
- **用途**：仰拍高楼、俯拍深渊

### 大气透视
- **描述**：远处物体对比度降低、偏蓝
- **情绪**：深远、梦幻、层次
- **用途**：风景、大场景

---

## 负空间运用

### 负空间 (Negative Space)
- **描述**：主体周围的空白区域
- **情绪**：
  - 大量负空间：孤独、渺小、自由、极简
  - 少量负空间：压迫、紧张、拥挤
- **用途**：
  - 表现孤独感：角色在一侧，大量空白
  - 表现压迫感：角色填满画面
  - 创造期待：角色看向空白处

### 留白方向
- **视线留白**：在角色视线方向留白
  - 情绪：期待、思考、目标
- **运动留白**：在角色运动方向留白
  - 情绪：前进、自由、目标
- **无留白**：角色紧贴画面边缘
  - 情绪：被困、压迫、紧张

## 构图情绪速查

| 情绪 | 推荐构图 |
|------|----------|
| 平静/稳定 | 对称、中心、水平线 |
| 紧张/不安 | 荷兰角、对角线、不平衡 |
| 孤独/隔离 | 大量负空间、远景、框架式 |
| 亲密/温暖 | 特写、浅焦、填充构图 |
| 力量/权威 | 低角度、中心、对称 |
| 脆弱/无力 | 高角度、小主体、大负空间 |
| 混乱/疯狂 | 倾斜、手持、跳切 |
| 神秘/悬疑 | 框架式、部分遮挡、阴影 |
| 自由/开放 | 远景、水平线、大天空 |
| 压迫/封闭 | 低天花板、前景遮挡、紧凑构图 |
