# 情绪与镜头语言对照表

## 紧张/悬疑 (Tension/Suspense)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 特写、大特写（聚焦细节）|
| 角度 | 低角度（威胁感）、荷兰角（不安）|
| 运动 | 缓慢推进、手持微抖、固定镜头 |
| 构图 | 不平衡、部分遮挡、框架式 |
| 光影 | 高对比、深阴影、侧光/底光 |
| 色调 | 冷蓝/绿、低饱和 |
| 节奏 | 慢 - 快交替、突然静止 |

### 技巧组合
- **缓慢推镜头** + **特写** = 紧张升级
- **固定镜头** + **长时长** = 等待的焦虑
- **荷兰角** + **手持** = 心理失衡
- **框架式构图** + **阴影遮挡** = 被困感
- **突然切到特写** = 惊吓/揭示

### 经典场景
- 侦探进入黑暗房间：手持 + 低照度 + 缓慢探索
- 倒计时场景：特写交替（钟表/角色脸/炸弹）
- 被跟踪：主观视角 + 回头特写 + 脚步声

## 浪漫/温情 (Romance/Warmth)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 中近景、特写（亲密感）|
| 角度 | 平视、轻微仰视（美化）|
| 运动 | 缓慢弧镜头、柔和斯坦尼康 |
| 构图 | 三分法、对称、负空间（两人之间）|
| 光影 | 低对比、逆光轮廓光、柔光 |
| 色调 | 暖橙/金、高饱和 |
| 节奏 | 慢、长镜头、慢动作 |

### 技巧组合
- **逆光** + **轮廓光** = 梦幻光晕
- **慢动作** + **特写** = 情感放大
- **浅焦** + **散景** = 世界只剩彼此
- **弧镜头** + **双人镜头** = 围绕爱情的世界
- **匹配剪辑** = 情感连接

### 经典场景
- 初次相遇：慢动作 + 逆光 + 特写眼神
- 雨中拥抱：中景 + 冷环境暖主体 + 慢动作
- 告别：拉镜头 + 长镜头 + 渐行渐远

## 悲伤/孤独 (Sadness/Loneliness)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 远景、全景（渺小感）、特写（眼泪）|
| 角度 | 高角度（脆弱）、平视（共情）|
| 运动 | 缓慢拉镜头、固定镜头 |
| 构图 | 大量负空间、角色偏置、远离中心 |
| 光影 | 低照度、冷调、窗户光 |
| 色调 | 蓝灰、低饱和、冷色 |
| 节奏 | 慢、长镜头、静止 |

### 技巧组合
- **远景** + **大负空间** = 孤独渺小
- **高角度俯拍** + **蜷缩姿态** = 脆弱无助
- **缓慢拉镜头** = 疏离、结束
- **固定长镜头** = 停滞、无力
- **冷色调** + **低饱和** = 情感麻木

### 经典场景
- 独自坐在空房间：全景 + 固定 + 冷光
- 葬礼：高角度 + 慢速 + 灰暗色调
- 离别后：拉镜头 + 角色变小 + 空环境

---

## 愤怒/冲突 (Anger/Conflict)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 中景、特写（表情）、全景（动作）|
| 角度 | 低角度（力量）、荷兰角（混乱）|
| 运动 | 快速推拉、手持抖动、快速摇镜 |
| 构图 | 对角线、不平衡、紧凑 |
| 光影 | 高对比、硬光、侧光 |
| 色调 | 红/橙（愤怒）、高饱和 |
| 节奏 | 快切、短镜头、突然静止 |

### 技巧组合
- **快速剪辑** + **手持** = 混乱激烈
- **特写交替** = 对峙张力
- **荷兰角** + **低角度** = 失控的力量
- **跳切** = 情绪爆发
- **突然静止** = 爆发前的沉默

### 经典场景
- 争吵：快速 OTS 交替 + 推进特写
- 打斗：手持 + 快切 + 多角度
- 爆发前：固定长镜头 + 沉默 + 突然切

## 恐惧/恐怖 (Fear/Horror)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 特写（恐惧表情）、远景（未知威胁）|
| 角度 | 低角度（威胁）、高角度（受害者）、底光 |
| 运动 | 手持抖动、缓慢推进、突然快速 |
| 构图 | 部分遮挡、黑暗占据画面、框架式 |
| 光影 | 极低照度、高对比、底光/顶光 |
| 色调 | 冷绿/蓝、低饱和、单色 |
| 节奏 | 慢（buildup）+ 快（jump scare）|

### 技巧组合
- **黑暗占据 70% 画面** = 未知恐惧
- **缓慢推进** + **安静** = 紧张积累
- **突然切/快速推进** = 惊吓
- **底光** = 诡异扭曲
- **主观视角** = 代入恐惧

### 经典场景
- 探索黑暗：手持 + 手电筒光 + 缓慢
- 怪物出现：先阴影/局部 + 再揭示
- Jump scare：安静长镜头 + 突然巨响 + 快切

## 喜悦/兴奋 (Joy/Excitement)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 中景、全景（动作）、特写（笑容）|
| 角度 | 平视、轻微仰视（积极）|
| 运动 | 流畅跟随、弧镜头、升降 |
| 构图 | 平衡、开放、引导线向外 |
| 光影 | 明亮、低对比、自然光 |
| 色调 | 暖、高饱和、多彩 |
| 节奏 | 中等偏快、流畅剪辑 |

### 技巧组合
- **升降镜头** + **开阔场景** = 释放、自由
- **流畅跟随** = 快乐移动
- **多彩高饱和** = 活力
- **慢动作** = 享受时刻
- **广角** = 包容世界

### 经典场景
- 奔跑：斯坦尼康跟随 + 开阔环境 + 明亮
- 庆祝：全景 + 多彩 + 流畅运动
- 重逢：特写笑容 + 暖光 + 浅焦

## 力量/权威 (Power/Authority)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 全景（展示地位）、中景（姿态）|
| 角度 | 低角度仰拍（核心技巧）|
| 运动 | 缓慢推进、固定、平稳 |
| 构图 | 中心、对称、三角形 |
| 光影 | 强主光、轮廓光、顶光 |
| 色调 | 暖金（权力）或冷蓝（冷酷权力）|
| 节奏 | 慢、稳定、不急于剪辑 |

### 技巧组合
- **低角度仰拍** + **中心构图** = 威严
- **对称构图** + **缓慢推进** = 不可阻挡
- **轮廓光** = 英雄/神圣光环
- **长镜头不切** = 掌控感
- **他人俯视镜头配合** = 权力对比

### 经典场景
- 登场：低角度 + 缓慢 + 轮廓光
- 演讲：低角度 + 对称 + 稳定
- 王座/办公室：对称 + 中心 + 高位

## 神秘/未知 (Mystery/Unknown)

### 镜头选择
| 元素 | 推荐方案 |
|------|----------|
| 景别 | 远景（未知）、特写（线索细节）|
| 角度 | 平视（观察者）、隐蔽角度 |
| 运动 | 缓慢摇镜、缓慢推进、固定 |
| 构图 | 框架式、部分遮挡、负空间 |
| 光影 | 低照度、体积光、剪影 |
| 色调 | 冷蓝/紫、低饱和、单色 |
| 节奏 | 慢、长镜头、留白 |

### 技巧组合
- **剪影** + **逆光** = 身份隐藏
- **框架式** + **遮挡** = 窥视、部分信息
- **缓慢摇镜揭示** = 逐步发现
- **体积光** = 超自然、神圣神秘
- **不揭示全貌** = 保持神秘

### 经典场景
- 神秘人物：剪影/背光/部分遮挡
- 神秘地点：缓慢揭示 + 体积光
- 线索发现：特写细节 + 浅焦

## 复合情绪处理

现实场景常包含复合情绪，需分层设计：

### 悲喜交加 (Bittersweet)
- **视觉**：暖色调但低饱和
- **构图**：平衡但有负空间
- **节奏**：中等偏慢
- **示例**：婚礼上的离别、成功的代价

### 紧张期待 (Nervous Anticipation)
- **视觉**：中等对比、冷暖混合
- **构图**：轻微不平衡
- **节奏**：慢中穿插快
- **示例**：比赛前、告白前

### 愤怒悲伤 (Angry Sadness)
- **视觉**：高对比但冷色调
- **构图**：不平衡 + 紧凑
- **节奏**：快切后长静止
- **示例**：失去后的愤怒、崩溃
