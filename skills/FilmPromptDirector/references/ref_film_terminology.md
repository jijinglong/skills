# 影视编导术语速查

> 本模块为 FilmPromptDirector Skill 新建的影视编导术语参考文档。
> 所有术语的描述方式和格式均遵循 Seedance 2.0 提示词指南的中文自然语言风格，可直接用于提示词撰写。
> 加载时机：功能3（分镜拆解）、功能4（提示词撰写）、功能7（术语查询）

---

## 1 景别（画面中主体占比大小）

景别决定了主体在画面中的大小和观众与主体之间的心理距离。

| 景别 | 画面范围 | 效果与氛围 | 提示词用法示例 | 典型适用场景 |
|---|---|---|---|---|
| **大远景** | 极广阔空间，主体极小或不可见 | 渲染宏大环境，营造史诗感或孤独感 | "大远景展现荒漠尽头的一座孤城" | 影片开场、环境交代、史诗场景 |
| **远景** | 广阔空间，主体渺小 | 展现空间全貌，强调环境氛围 | "远景展现整片悬崖和竹林" | 建立场景、交代地理环境 |
| **全景** | 人物全身入画 | 展示人与环境的关系，交代空间位置 | "全景展示宿舍内一片欢声笑语的画面" | 场景总览、群戏、空间关系 |
| **中景** | 人物膝盖/腰部以上 | 兼顾动作与表情，最常用的叙事景别 | "中景平稳跟拍，暖黄色日光洒进走廊" | 日常对话、行走、一般叙事 |
| **近景** | 胸部以上 | 突出人物表情与情绪变化 | "镜头给到她的近景，随后她抬头" | 情绪转折、对白、情感戏 |
| **特写** | 面部或物体局部 | 极度聚焦细节，放大情绪或关键信息 | "镜头快速摇动并给到男人惊恐的特写" | 情绪高潮、关键道具展示 |
| **大特写** | 眼睛、嘴唇、手指等极端局部 | 营造极致的视觉冲击力和悬念感 | "大特写拍摄剑尖微微颤动的瞬间" | 悬念、微表情、细节物件 |

### 景别选择建议

- **叙事主体**（对话/行走）→ 中景、近景
- **建立空间**（场景开头）→ 远景、全景
- **情绪高潮**（转折/震撼）→ 特写、大特写
- **收尾定格**（结尾/余韵）→ 全景拉远、远景

## 2 机位（摄像机的位置和角度）

机位决定了观众"从什么视角"观看画面，直接影响情绪传达和叙事效果。

| 机位 | 摄像机位置 | 效果与氛围 | 提示词用法示例 | 典型适用场景 |
|---|---|---|---|---|
| **平视机位** | 与主体视线等高 | 平等客观的记录感，日常真实 | "镜头平视拍摄两人面对面交谈" | 日常场景、对话、纪实 |
| **俯拍** | 从上方向下拍摄 | 展现空间格局，或赋予主体渺小/脆弱感 | "镜头从上方俯拍人群穿梭的集市" | 空间展示、表达渺小/无力 |
| **俯瞰/鸟瞰** | 正上方垂直向下 | 上帝视角，展现宏大格局 | "无人机视角俯瞰整片悬崖和竹林" | 大场面、地图式展示 |
| **仰拍** | 从下方向上拍摄 | 赋予主体力量感、威严感、压迫感 | "仰拍角度拍摄他缓缓起身的背影" | 展现威严、英雄出场、建筑 |
| **侧拍** | 从主体侧面拍摄 | 展示侧面轮廓和动作线条 | "镜头从侧面中景拍摄她奔跑的姿态" | 行走/奔跑、侧脸特写 |
| **过肩镜头** | 从一个角色肩膀后方 | 建立两人对话的空间感和临场感 | "给白衣男子过肩镜头" | 双人对话、对峙 |
| **固定机位** | 摄像机完全不动 | 静观、客观记录，给主体更多表演空间 | "固定机位拍摄街头人来人往" | 静态场景、长镜头观察 |
| **手持镜头** | 手持拍摄有轻微晃动 | 纪实感、紧张感、临场感 | "手持镜头向前快速跟拍，画面带有轻微真实的晃动感" | 追逐、纪实、紧张氛围 |
| **第一视角** | 主角眼睛的位置（POV） | 沉浸式体验，强烈代入感 | "第一视角俯冲，体现出园区的科技感" | 沉浸式体验、探索 |
| **航拍/无人机视角** | 空中高处 | 大气磅礴、空间开阔 | "无人机视角从空中缓缓掠过城市天际线" | 风景、大场面、开场 |

## 3 构图（画面元素的空间布局）

构图决定了画面中各元素的位置关系，影响视觉重心和观看节奏。

| 构图方式 | 布局特点 | 效果与氛围 | 提示词用法示例 |
|---|---|---|---|
| **中心构图** | 主体居中 | 视觉焦点明确，庄重稳定 | "以高楼为视觉中心" |
| **三分法构图** | 主体位于三等分交叉点 | 平衡且富有动感 | "人物位于画面右侧三分之一处" |
| **对称构图** | 左右或上下对称 | 庄重、和谐、仪式感 | "两人分立山崖两端" |
| **前景遮挡** | 利用前景虚化增强层次 | 空间纵深感、沉浸感 | "前景竹叶虚化，中景人物清晰" |
| **框架构图** | 利用门窗/拱门等框架 | 引导视线聚焦、增强层次 | "透过宿舍门框望向走廊中的人物" |
| **引导线构图** | 利用道路/栏杆等线条 | 引导视线至主体，增强纵深 | "走廊的透视线条引导视线至尽头的人物" |
| **留白构图** | 大面积空白/简洁 | 孤独感、诗意、呼吸感 | "人物位于画面底部，上方大面积天空留白" |
| **对角线构图** | 主体沿对角线排列 | 动感、张力、不稳定感 | "人物沿画面对角线奔跑" |

## 4 运镜（摄像机的运动方式）

运镜是镜头的运动方式，直接影响画面节奏和情绪。

> ⚠️ 一个镜头里尽量只指定 **1 种运镜方式**，不要同时要求推拉摇移。

| 运镜方式 | 运动描述 | 效果与情绪 | 提示词用法示例 | 速度修饰建议 |
|---|---|---|---|---|
| **推镜/推近** | 镜头向主体靠近 | 引导注意力、聚焦、强调重要细节 | "全景缓慢推近" / "镜头平稳推近至保温杯近景" | 缓慢推近 / 快速推近 |
| **拉镜/拉远** | 镜头远离主体 | 释然、结束感、揭示空间全貌 | "镜头缓慢拉远，定格在空荡的街道" | 缓慢拉远 / 急速拉远 |
| **横摇/摇镜** | 镜头左右水平旋转 | 横向空间展示、视线引导、场景巡视 | "镜头向右横摇，切换至另一画面" | 缓慢横摇 / 快速摇动 |
| **纵摇/俯仰摇** | 镜头上下垂直旋转 | 纵向空间展示、由脚到头展示人物 | "镜头缓慢自下而上摇动，展现建筑全貌" | 缓慢纵摇 |
| **横移/平移** | 镜头水平方向移动 | 平稳叙事、伴随行进 | "平稳横移跟随人物行走" | 平稳横移 / 缓慢平移 |
| **跟拍/跟随** | 镜头跟随主体移动 | 伴随感、行进感、贴身视角 | "中景平稳跟拍" / "镜头跟拍手部微微旋转" | 平稳跟拍 / 快速跟拍 |
| **环绕** | 镜头围绕主体旋转 | 展示全貌、仪式感、聚焦主体 | "镜头环绕她半圈，从正面推到背影" | 缓慢环绕 / 快速环绕 |
| **升降** | 镜头垂直上下移动 | 空间切换、情绪升华、俯仰转换 | "镜头缓慢上升，俯瞰全景" | 缓慢上升 / 缓慢下降 |
| **变焦** | 改变焦距远近 | 聚焦/展开、画面过渡 | "镜头变焦渐隐到远景" | 缓慢变焦 |
| **甩镜** | 镜头快速甩动 | 紧张、突发、视线急转 | "镜头快速甩向门口方向" | 快速甩镜 |

### 运镜组合建议

虽然单个镜头只推荐 1 种运镜，但不同镜头之间可以形成运镜节奏变化：

| 情绪节奏 | 推荐运镜组合（跨镜头） |
|---|---|
| 平静→紧张 | 固定机位 → 手持跟拍 → 快速甩镜 |
| 宏大→聚焦 | 航拍远景 → 缓慢推近 → 特写定格 |
| 展示→揭示 | 环绕展示 → 拉远全景 → 推近新主体 |
| 对话场景 | 过肩镜头（A→B）→ 近景（B反应）→ 中景（双人） |

## 5 光影氛围（画面的光线处理和情绪渲染）

光影直接决定画面的情绪基调和视觉质感。

| 光影类型 | 光源描述 | 效果与氛围 | 提示词用法示例 |
|---|---|---|---|
| **暖黄色日光** | 偏暖的自然日光 | 温馨、怀旧、舒适、亲密 | "暖黄色日光从窗外洒进走廊" |
| **冷调低饱和** | 蓝灰冷色调，低饱和度 | 凛冽、悲壮、萧瑟、克制 | "冷调低饱和，电影胶片质感" |
| **逆光** | 光源在主体后方 | 主体轮廓光，浪漫或神秘感 | "逆光勾勒人物轮廓，氛围感强烈" |
| **侧光** | 光源在主体侧面 | 明暗对比强烈，戏剧张力 | "侧光打在人物脸上，阴影分明" |
| **顶光** | 光源在主体正上方 | 神圣或压迫感 | "顶光照射，人物面部形成深邃阴影" |
| **底光** | 光源在主体下方 | 诡异、恐怖、不安 | "底光向上照射，面部呈现不自然阴影" |
| **柔光** | 漫射均匀的柔和光线 | 温柔、梦幻、唯美 | "光影柔和，画面如梦似幻" |
| **硬光** | 直射的强烈光线 | 锐利、对比强烈、力量感 | "硬光投射出锐利分明的阴影" |
| **自然光** | 真实场景的自然光照 | 真实、纪实感 | "色彩自然，光影柔和" |
| **霓虹光** | 彩色霓虹灯光 | 都市、赛博朋克、繁华 | "霓虹闪烁的未来都市" |
| **烛光/篝火光** | 暖色跳跃光源 | 温暖、亲密、古朴 | "烛光摇曳，映照出人物侧脸的暖色" |
| **月光** | 冷色柔和环境光 | 宁静、孤寂、浪漫 | "月光洒在水面上，泛起银白色的波光" |

### 光影氛围组合

| 情绪目标 | 推荐光影组合 |
|---|---|
| 温馨日常 | 暖黄色日光 + 柔光 + 自然光 |
| 江湖悲壮 | 冷调低饱和 + 侧光 + 逆光 |
| 赛博未来 | 霓虹光 + 硬光 + 冷色调 |
| 恐怖悬疑 | 底光 + 硬光 + 冷调低饱和 |
| 浪漫唯美 | 逆光 + 柔光 + 暖色调 |

## 6 镜头切换与转场

镜头之间的切换方式影响叙事节奏和观看体验。

| 切换方式 | 描述 | 效果与节奏 | 提示词用法示例 |
|---|---|---|---|
| **硬切** | 直接从一个镜头切到下一个 | 节奏明快、干脆利落 | "镜头切到室内中景" / "镜头切回地面近景" |
| **渐隐/淡出** | 画面逐渐变暗或模糊 | 时间流逝、段落结束 | "画面逐渐模糊，后出现Logo" |
| **渐显/淡入** | 从暗/模糊到清晰 | 新段落开始、梦境苏醒 | "画面从黑暗中渐渐显现晨光" |
| **叠化** | 两个画面短暂重叠交融 | 时间跳跃、回忆过渡 | "画面叠化过渡到童年的回忆场景" |
| **动作转场** | 利用主体动作衔接 | 流畅自然、动态连贯 | "借着转身惯性顺势切换至下一场景" |
| **遮挡转场** | 利用物体遮挡画面后切换 | 巧妙自然 | "路人经过镜头前遮挡画面，随即切换到新场景" |
| **变焦渐隐** | 焦距变化实现过渡 | 空间压缩/展开感 | "镜头变焦渐隐到远景" |

## 7 视觉风格速查

可在提示词末尾使用的风格关键词组合：

| 风格类别 | 提示词关键词组合 |
|---|---|

## 8 画质与稳定性约束词模板

以下约束词可在提示词末尾选择性组合使用：

### 画质类

```
高清，细节丰富，电影质感
色彩自然，光影柔和
光影层次丰富
```

### 人物稳定性类

```
人物面部稳定不变形，动作自然流畅，无卡顿无闪烁
人物面部和身体比例稳定不变形，动作连贯自然，不僵硬，无穿模无卡顿
```

### 瑕疵约束类

```
保持无字幕
避免生成任何文字或字幕
不要生成水印
不要生成Logo
```

### 多人物约束类

```
视频全程禁止出现外形、着装、配饰完全一致的人物，禁止生成同款分身、双胞胎效果，同一画面中仅保留单个对应人物，不出现人物重复复刻
```

## 9 提示词复杂度评估指标

| 评估维度 | 低复杂度（✅安全） | 中等复杂度（⚠️注意） | 高复杂度（⚠️建议优化/分段） |
|---|---|---|---|
| 分镜数量 | 1-3 个镜头 | 4-5 个镜头 | 6+ 个镜头（建议使用功能8拆分段落） |
| 主体数量 | 1-2 个主体 | 3-4 个主体 | 5+ 个主体（建议分步或分组制作） |
| 素材数量 | 2-3 个素材 | 4-5 个素材 | 6+ 个素材（建议精炼及去重） |
| 运镜指令 | 每镜头1种 | 偶有2种 | 频繁多种叠加（建议精简为单一运镜） |
| 文字长度 | <600字 | 600-1200字 | 1200+ 字（仅供检查是否存在冗余叙事） |
| 特殊要求 | 无文字/特效 | 含文字或简单特效 | 复杂特效+多文字（可能降低稳定性） |

> ⚠️ **红线警告**：
> 1. 复杂度评估仅作为生成策略和优化参考维度，**绝对禁止将其作为审核不通过项（❌）**。
> 2. **绝对禁止**为了降低复杂度或缩短字数，精简、阉割或删除在功能 3 和功能 4 中设计好的分镜细节、人物特征、动作描述、微表情（如眨眼描述）和镜头语言。提示词的画面细节描述必须充实饱满。
