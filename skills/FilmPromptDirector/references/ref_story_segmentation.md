# 剧情拆分规划模块

> 本模块为功能8（剧情拆分规划）提供参考规则。
> 加载时机：功能8（剧情拆分规划）

---

## 1 剧情拆分原则

当用户提供一段完整的长剧情时，需要将其拆分为多个独立的 **Script 片段**。每个片段应是一个可独立生成视频的最小叙事单元。

### 1.1 拆分维度

按以下四个维度综合判断拆分点，**任一维度出现明显变化即构成拆分点**：

| 维度 | 拆分信号 | 示例 |
|---|---|---|
| **场景/时空转换** | 地点改变、时间跳跃（白天→夜晚、回忆→现实） | 从咖啡店切到街道 |
| **情绪曲线节点** | 情绪基调发生明显转折（平静→紧张、欢乐→悲伤） | 对话中突然得知噩耗 |
| **角色进出场** | 核心角色加入或离开画面，导致互动关系变化 | 第三人加入对话 |
| **动作强度变化** | 从低动态"文戏"过渡到高动态"武戏"，或反之 | 对话结束后开始追逐 |

### 1.2 拆分粒度

- **最小粒度**：一个连贯场景内的单一事件（如一段对话、一次打斗）
- **最大粒度**：同一场景、同一角色组合、同一情绪基调下的连续事件链
- **推荐**：每段 script 对应 1-3 个分镜，确保模型能在单次生成中完成

### 1.3 拆分禁忌

- ❌ 不要在一个连贯动作的中途拆分（如角色正在说话的句子中间）
- ❌ 不要将紧密因果关系的事件拆到不同段（如开门→进入应在同一段）
- ❌ 不要为了凑数而过度细分（每段应有完整的叙事意义）

## 2 制作策略判定矩阵

每段 script 必须标注制作策略：**视频延长（EXT）** 或 **分段拼接（CUT）**。

### 2.1 策略定义

| 策略 | 代号 | 适用场景 | 核心特点 |
|---|---|---|---|
| **连续长镜头（视频延长）** | `EXT` | 单一场景内的"文戏"：长对话、情绪递进、单一路径移动 | 沉浸式、连贯的一镜到底效果 |
| **场景/动作转折（分段拼接）** | `CUT` | 剧情转折或复杂、快速的"武戏"：追逐、打斗、蒙太奇等 | 独立生成片段再剪辑组合，保证节奏与视觉冲击力 |

### 2.2 详细判定规则

| 分镜特征 | 推荐策略 | 原因 |
|---|---|---|
| 同一场景、同一组人物、连续对话/动作 | `EXT` | 保持连贯性与沉浸感 |
| 场景切换、视角剧变、时间跳跃 | `CUT` | 场景差异大，需独立生成 |
| 剧烈动作（追逐/打斗/爆炸） | `CUT` | 高动态动作分段可控性更好 |
| 情绪递进、缓慢渲染（如凝视、沉思） | `EXT` | 保持情绪连续性 |
| 蒙太奇式快剪（多个短画面交替） | `CUT` | 需要独立生成后快速剪辑 |
| 角色在同一空间内连续行走/移动 | `EXT` | 动线连贯，适合一镜到底 |
| 角色从一个空间移动到另一个空间 | `CUT` | 跨场景需分段处理 |

### 2.3 混合策略

实际制作中通常结合两种方式：

- **先延长再拼接**：先用 `EXT` 生成连贯对话，再拼接空镜或转场片段
- **先拼接再延长**：先分段生成多个关键画面，再用 `EXT` 补充过渡
- **段内混合**：同一段 script 的多个分镜可能混用策略（在功能3分镜拆解时进一步细化）

> 💡 功能8阶段仅做**段级策略标注**（整段是 EXT 还是 CUT），分镜级别的策略细化在功能3中完成。

## 3 段落素材配置规划

### 3.1 四种功能角色

每段 script 的素材需求按以下四种功能角色分析：

| 功能角色 | 作用 | 典型素材 |
|---|---|---|
| **角色锚定** | 锁定角色外观 | 面部特写（大头照）、全身照 |
| **场景定调** | 锁定环境与风格 | 场景参考图 |
| **运镜参考** | 锁定镜头语言与动作节奏 | 运镜参考视频 |
| **节奏氛围** | 用音频控制情绪、音色 | 背景音乐、音效片段 |

### 3.2 推荐配置

每段 script 推荐 **4-5 个素材**：
- 角色图 1-2 张（面部特写 / 全身）
- 场景图 1 张
- 运镜视频 1 段
- 音频 1 段

> ⚠️ 不建议用满素材上限，过多素材会导致模型难以判断特征优先级，易出现风格冲突、主体识别模糊、生成效果偏离预期等问题。

### 3.3 跨段素材复用规则

| 场景 | 素材策略 |
|---|---|
| 同一角色跨段出场 | **复用同一组角色锚定素材**（同一张大头照 + 全身照），保持角色一致性 |
| 同一场景跨段延续 | **复用同一张场景定调图**，保持环境风格连贯 |
| 不同场景但相同角色 | 角色素材复用，场景素材替换 |
| 情绪氛围变化 | 更换音频素材，其余可复用 |
| 全新场景 + 全新角色 | 全套素材重新准备 |

### 3.4 段落素材需求分析输出格式

对每段 script 输出素材需求：

```
📦 S{序号} 素材需求
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎭 角色锚定：{角色列表} {复用/新增}
🏞️ 场景定调：{场景描述} {复用/新增}
🎬 运镜参考：{运镜类型} {复用/新增}
🎵 节奏氛围：{音频描述} {复用/新增}
📊 素材总计：{N}个（{M}个复用 + {K}个新增）
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 4 Script 文件命名规范

### 4.1 命名格式

```
S{序号}_{制作策略}_{场景关键词}.txt
```

| 组成部分 | 规则 | 示例 |
|---|---|---|
| `S{序号}` | 两位数序号，按剧情时间顺序排列，从 `01` 开始 | `S01`, `S02`, `S10` |
| `{制作策略}` | `EXT`（视频延长/长镜头）或 `CUT`（分段拼接） | `EXT`, `CUT` |
| `{场景关键词}` | 2-4个汉字，概括该段核心场景或动作 | `仓库对话`, `追逐打斗` |

### 4.2 命名示例

```
script/
├── S01_EXT_清晨咖啡店.txt
├── S02_CUT_街头追逐.txt
├── S03_EXT_公园对话.txt
├── S04_CUT_蒙太奇回忆.txt
└── S05_EXT_日落告别.txt
```

### 4.3 文件内容格式

每个 script 文件包含以下结构：

```
━━━━━━━━━━━━━━━━━━━━━━━━━
📋 S{序号}：{段落标题}
━━━━━━━━━━━━━━━━━━━━━━━━━

【制作策略】{EXT 视频延长 / CUT 分段拼接}
【策略说明】{为什么选择此策略的简要理由}

【剧情内容】
{该段的完整剧情描述}

【涉及角色】{角色列表}
【场景环境】{场景描述}
【情绪基调】{情绪关键词}
【预估分镜数】{N}个镜头

【素材需求】
🎭 角色锚定：{素材需求}
🏞️ 场景定调：{素材需求}
🎬 运镜参考：{素材需求}
🎵 节奏氛围：{素材需求}

【衔接说明】与前段/后段的过渡方式
━━━━━━━━━━━━━━━━━━━━━━━━━
```

### 4.4 特殊命名场景

| 场景 | 命名处理 |
|---|---|
| 同一场景分多段（因情绪转折） | 场景关键词后加字母区分：`S02_EXT_仓库对话A.txt`、`S03_CUT_仓库打斗B.txt` |
| 蒙太奇/闪回 | 使用 `蒙太奇` 或 `闪回` 作为关键词：`S04_CUT_童年闪回.txt` |
| 空镜/转场 | 使用 `空镜` 或 `转场` 作为关键词：`S03_CUT_城市空镜.txt` |

## 5 拆分流程总结

```
用户输入完整剧情
       ↓
第一步：通读剧情，标记所有拆分点（场景/情绪/角色/动作维度）
       ↓
第二步：将剧情分割为 N 个 Script 片段
       ↓
第三步：为每段标注制作策略（EXT / CUT）
       ↓
第四步：为每段分析素材需求（四种功能角色）
       ↓
第五步：生成段落总览表 + 各段 Script 文件
       ↓
衔接功能3（分镜拆解）→ 逐段进入后续流程
```
