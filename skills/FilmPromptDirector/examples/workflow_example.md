# 完整工作流演示案例

> 本文档展示 FilmPromptDirector Skill 从意图挖掘到最终提示词输出的完整工作流程。

---

## 场景设定

**用户需求**：制作一个 15 秒的咖啡品牌广告短片

---

## 步骤 1：意图挖掘

### Agent 提问

> 你好！我是你的 AI 影视编导。让我先了解你的创作需求：
>
> 1. 你想制作什么类型的视频？
> 2. 这个视频要传达什么情感/信息？
> 3. 你心目中的视觉风格是什么样的？
> 4. 预计的视频时长？
> 5. 你手头有哪些参考素材？

### 用户回答

> 做一个咖啡品牌的广告，想要温暖治愈的感觉。有一个女孩的照片和咖啡店的照片。大概15秒左右，日系清新风格。

### 需求摘要卡片

```
📋 需求摘要
━━━━━━━━━━━━━━━━━━━━━━━━━
▸ 类型：品牌广告
▸ 主题：咖啡品牌形象
▸ 情感基调：温暖治愈
▸ 视觉风格：日系清新
▸ 目标时长：约15秒
▸ 现有素材：女孩照片×1，咖啡店照片×1
▸ 缺少素材：运镜参考视频、背景音乐
▸ 特殊需求：无
━━━━━━━━━━━━━━━━━━━━━━━━━
```

---

## 步骤 2：剧情简纲

### 方案 A：「一杯之间」

```
【方案 A：一杯之间】
▸ 核心叙事：女孩在咖啡店点单，等待，品尝，露出满足微笑
▸ 情绪曲线：期待 → 等待 → 满足 → 治愈
▸ 预估分镜数：3 个镜头
▸ 关键视觉意象：拉花、蒸汽、阳光、微笑
▸ 推荐风格：日系清新 + 暖色调柔光
```

### 方案 B：「清晨仪式」

```
【方案 B：清晨仪式】
▸ 核心叙事：清晨女孩推门进入咖啡店，阳光洒入，一杯咖啡开启美好一天
▸ 情绪曲线：宁静 → 温暖 → 期待 → 美好
▸ 预估分镜数：3 个镜头
▸ 关键视觉意象：清晨阳光、推门、咖啡拉花、微风
▸ 推荐风格：日系清新 + 自然光
```

### 方案 C：「温暖传递」

```
【方案 C：温暖传递】
▸ 核心叙事：店员递上咖啡，女孩双手捧住，温暖从指尖传递到心间
▸ 情绪曲线：平静 → 触感温暖 → 内心温暖 → 微笑绽放
▸ 预估分镜数：3 个镜头
▸ 关键视觉意象：双手、杯壁蒸汽、指尖温度、柔和笑容
▸ 推荐风格：日系清新 + 特写细节
```

**用户选择**：方案 B

---

## 步骤 3：分镜拆解

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎬 分镜表：「清晨仪式」
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【镜头 1】
├─ 景别/机位：中景 → 推近至近景 / 平视机位
├─ 运镜方式：缓慢推近
├─ 主体动作：女孩轻轻推开咖啡店玻璃门，脚步轻快走入店内
├─ 场景环境：清晨的咖啡店门口，暖黄色日光从门外洒进
├─ 情绪表达：嘴角微微上扬，眉眼舒展
├─ 音频信息：（轻柔的钢琴背景音乐）<门铃叮当响>
└─ 衔接说明：推门动作自然过渡到店内环境

【镜头 2】
├─ 景别/机位：特写 / 俯拍
├─ 运镜方式：固定机位
├─ 主体动作：咖啡师的手缓慢倒出拉花，奶白色液体在咖啡表面形成花纹
├─ 场景环境：吧台桌面，木质纹理，暖色灯光
├─ 情绪表达：手部动作稳定流畅，散发专业与温暖
├─ 音频信息：（钢琴音乐持续）<咖啡液体流动的细微声>
└─ 衔接说明：拉花完成后自然切至女孩

【镜头 3】
├─ 景别/机位：近景 → 缓慢拉远至中景 / 平视
├─ 运镜方式：缓慢拉远
├─ 主体动作：女孩双手捧起咖啡杯，轻轻吹一口，小口品尝后微微闭眼，嘴角上扬
├─ 场景环境：咖啡店窗边座位，窗外阳光洒入
├─ 情绪表达：闭眼+嘴角上扬（满足感外化）
├─ 音频信息：（钢琴音乐渐弱）

• 也可分段生成后拼接，视效果而定

📦 素材准备清单
━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎭 角色锚定
  • @图片1：女孩面部特写（大头照）— 建议补充
  • @图片2：女孩全身/半身照（已有）

🏞️ 场景定调
  • @图片3：咖啡店场景参考（已有）

🎵 节奏氛围
  • @音频1：轻柔钢琴背景音乐 — 建议补充

📋 上传顺序：图片1 → 图片2 → 图片3 → 音频1
━━━━━━━━━━━━━━━━━━━━━━━━━━━
```

# 剧情拆分规划演示案例（功能 8）

> 本案例展示当用户提供一段完整长剧情时，功能 8 如何将其拆分为多个 Script 片段。

---

## 场景设定

**用户需求**：制作一段奇幻动作短片，用户直接提供了完整剧情文本。

---

## 步骤 0：用户输入完整剧情

> 黄昏时分，铃兰独自一人走在废弃工厂区的窄巷中，四周是生锈的铁架和破碎的玻璃窗，夕阳的余晖斜照在她身上。她停下脚步，看见前方仓库的铁门半开着，从门缝里透出昏黄的灯光。铃兰犹豫了一下，推开铁门走了进去。
>
> 仓库内部空旷而昏暗，只有头顶几盏老旧的工业吊灯发出微弱的光。铃兰慢慢向前走，脚步声在空荡的空间里回响。突然，从仓库深处传来沉重的脚步声，地面微微震动。一个巨大的身影从阴影中走出——是巧克力，身高210厘米的少女，穿着工装连体裤，围着粗布围裙。她低头看着只有120厘米的铃兰，嘴角微微上扬。
>
> 巧克力蹲下来，与铃兰平视，用低沉温柔的声音说了句"你来了"。铃兰紧张地点了点头，双手不自觉地攥紧了背包带。两人对视片刻，巧克力伸出手，轻轻拍了拍铃兰的头顶。
>
> 突然，仓库的铁门被猛力撞开，三个蒙面人冲了进来。巧克力猛地站起身，身体挡在铃兰前面，地板被她起身的力量震得嗡嗡作响。蒙面人向他们冲来，巧克力一把抓起身旁的金属管，挥臂横扫，将第一个蒙面人击飞。第二个蒙面人绕到侧面试图偷袭铃兰，巧克力转身一脚踢翻了旁边的铁桶挡住去路，碎片四溅。
>
> 混战中，铃兰躲在角落，紧紧抱住背包。巧克力与第三个蒙面人扭打在一起，两人撞上了货架，各种零件和工具哗啦啦掉落。巧克力最终将对手摔倒在地。
>
> 战斗结束，仓库一片狼藉。巧克力转身走向铃兰，身上沾满灰尘。她再次蹲下来，检查铃兰是否受伤。铃兰的眼眶红了，但忍住没哭，只是轻轻点了点头表示没事。巧克力露出释然的微笑，伸手把铃兰额前的碎发拨到耳后。
>
> 两人并肩走出仓库，夕阳已经快要落山，天空被染成深橙色。巧克力牵着铃兰的手，铃兰小小的手被巧克力的大手完全包裹。她们的影子在地面上一长一短，慢慢走向远方。

---

## 步骤 1：功能 8 拆分分析

### Agent 分析过程

> 通读剧情后，识别出以下拆分点：
>
> 1. **场景转换**：巷道外 → 仓库内（进入仓库）
> 2. **角色进场**：巧克力从阴影中出现
> 3. **情绪转折**：温柔对话 → 突发战斗（蒙面人闯入）
> 4. **动作强度变化**：文戏对话 → 武戏打斗
> 5. **情绪转折**：战斗 → 战后温情
> 6. **场景转换**：仓库内 → 仓库外（走出仓库）
