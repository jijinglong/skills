# 摄影、动作与交付示例

## 导演与摄影的写法

| 要解决的问题   | 写到正文中的可观察内容                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------- |
| 空间与观看位置 | 主体相对位置、视线、出入口、距离与危险方向；必要时以中景／中全景先建立关系                                 |
| 摄影切换       | 此刻为何切、切到哪个对象、景别和方向如何变化；动作匹配、视线连接或反应承接保持轴线                         |
| 运镜与焦点     | 跟随谁到哪里、揭开什么信息；移焦写明前后对象，推近服务人物决定，不让每段都同样慢推                         |
| 动作与力量     | 谁发起、打向哪里、如何应对、何处接触、产生什么变化、余势怎样落定；关键动作保留手脚与器械可读性             |
| 表演与节奏     | 触发事件在前，停顿、转眼、收手、松力等选择在后；为对手反应留画面，不默认加入喊叫、慢动作或碎切             |
| 灯光与质感     | 由已确定的窗、灯、炉火等光源成立，脸、手和接触点可辨；跨切光向与材质连续，不擅自添加与场景冲突的天气或色彩 |

换机位后仍能判断谁在何处、谁在行动、力量传向哪里。动作匹配切近用于证实接触或信息，再以关系景确认结果；跨轴时提供足以重建空间的画面。

## 武戏、交接与机关

一个动作回合通常在同一次生成中覆盖发起、应对、接触和余波。多次攻击要有各自落空或受制的终点，不能把“先后三击”画成三把刀同时飞来。

逐次检查双手：端碗、持刀、接刃、卷袖或背人不能由同一只手并发完成。交接按接住、松手、持有、放置及取回交代，物体不会因切镜复制。重量先有支撑才能转移，工具楔住、松开握持与抽走是不同状态；断裂、翻转、坠落由前面的接触与施力触发。

伤势、去披风、撕衣、裹手、卸甲与外衣交付成为后续段的起始事实，直到剧情允许改变。道具藏在衣物或箱中时，首帧不为“展示参考物”把它提前拿出；状态图中的其他人物、盔甲或后续损坏不进入当前画面。

## 一个可复用的交付例子

以下是虚构示例。角色、左右手和站位由本例设计，不代替项目事实；若使用已有首帧，先核对图片，不能声称模型已看过未提供的图。

**制作信息（不提交给视频模型）**

- 本集生成段：桌边截刀。剪辑预算12秒；执行使用模型原生智能时长，实际输出后复核，不把预算作为必须填满的长度。
- 模式：单张首帧，首帧待制作。图像参数、视频输出规格和声音开关分别在执行参数中设置。
- 起点：反派站桌外举刀；匠人坐桌内，右手空着、左手握厚布；徒弟在桌端。完整刀和厚布都尚未完成动作。
- 边界理由：同一空间的一次攻防及其反应合为一段；之后证据说明另起，不跨集。
- 风险：断裂与接刃需完整可读。实际结果偏差过大时先收紧并发动作，再判断是否调整生成边界。

**可提交正文**

```text
从首帧自然开始。稳定的斜侧中景看清反派、匠人与桌端徒弟的关系。反派向匠人挥刀，匠人右手一指敲中刀背；接触完成时动作匹配切同侧近景，刀从受力处裂开。

回到包含桌端的中景，断刃沿连续轨迹飞向徒弟；匠人用左手厚布迎住、包卷卸力，再连布落向砧板。落定才切近确认厚布裹住断刃，没有裸手抓刃。

沿徒弟收回手的反应切到反派低看断柄，最后回到桌边关系景。断刃留在砧板的厚布中，断柄仍在反派手里，徒弟未受伤。
```

示例没有对白。实际有对白时逐句保留原文、说话人和指定语气，不自补台词。正文中不写“12秒、720p、无声”等执行参数，不把后期事项混成模型应生成的画面。

## 成本与结果的判断

预算分开列视频输出、首帧输出、输入参考图和可预期的重做范围；核对供应商是否按输出tokens、秒数或其他单位计费。相同总秒数合并为更少任务时，视频单轮费用可能接近，但首帧次数减少，某处失败后需要重做的长度也可能变大。未评估真实结果时不编造成功率或固定重试倍率。

首帧检查人物、手、道具、姿态和空间是否支持接下来的动作；视频完整播放后再核对动作顺序、切镜、表演和余波。能解码、工程测试通过和画面验收分别记录。
