# 线条角色打斗动效

从 [动作与授权](references/animation-library.md) 选取素材。技能附带四条原始 GLB、可直接读入浏览器的二维轨迹，以及为这套骨架导出轨迹的 Blender 脚本。只需要素材时交付相应文件和来源。使用其他骨架时先检查关节名、前进方向、地面高度和位移所用骨骼。

- 用身体关键帧确定挥斩节拍，把动作时刻、刀光和碰撞结果写入同一事件表。做效果对照时，让命中和落空共用同一进攻轨迹，分别安排格挡、反应或闪避。用双人站位保证刀光、刀刃和受击点相交或错开。
- 按绝对时间取样身体和效果。停顿期间保持身体时间不变，让火花、闪光和震屏按实际经过时间衰减。落空可保留刀光和残影。只有接触事件才触发命中反馈。
- 保留单动作预览，便于检查手腕剑轴、脚底、面向和位移。定帧对照至少看触发前、触发帧和收势，检查格挡时两把剑、受击时刀刃与角色、落空时两人之间的距离。
- 用 Motion Kit 的按时间绘制方式组织 Canvas。要叠像素刀光或冲击图集时，参考 `create-procedural-pixel-effects` 的图集取帧和锚点说明。合成、调参和离线预览可直接使用本技能的二维轨迹。
