# Seedance 2.5 提示词

按[官方资料与能力边界](references/model-boundaries.md)核对目标型号和执行端，再编写正文。需要完整制作包或示例时读[生成方案与示例](references/prompt-plan.md)。这是自定义工作流，不是官方发布的 Skill。

采用官方 `sd25-pe` 组织生成目标、实际参考职责、事件脚本与保持关系；安装的第三方2.0方言不参与2.5新任务。第三方2.5经验中的每切必须关键帧、连续第二段必须extend均不作为官方硬限制。一次生成可以包含多个摄影镜头，普通同场续接可显式使用真实尾帧。项目约定优先于第三方模板。

## 先锁定事实和路由

读取剧本原文、集号、角色定义及当前形象、声音绑定、可访问素材与执行端能力。默认保留人物、对白和故事事实；用户授权审改剧本时，先在源稿修正有问题的事实、对白与信息顺序，再依当前源稿更新提示词、附件职责、音色映射和后期字层，不以旧对白冻结剧情漏洞。无法查看素材时保留已有引用，不凭文件名猜外观，不声称已审看。

区分文生、严格首帧、图片／音频联合参考。只有真实上传并指定 `first_frame` 的图片才是严格首帧；`reference_image` 作为开场状态参考，不承诺像素级锁定。2.5 支持纯音频参考。严格首帧／首尾帧与全模态参考互斥；需要角色音色时使用全模态参考并在正文明确开场状态。执行前核对应用当前接入路由，分别处理参考生成、首尾帧、编辑和延长。

素材逐张分配职责：开场状态、某人的身份与服装、环境或道具。按真实附件顺序使用图片编号，音频另行编号；同一主体使用稳定名称，群像明确对应哪个人物。素材库 ID 不能代替正文中的图片／视频编号。首帧制作附件和视频附件是两份清单，不自动复制编号。未采用素材不强行入镜，缺少的素材只列在制作备注。

审查或重排后执行[可见角色与素材覆盖复核](references/prompt-plan.md#可见角色与素材覆盖复核)。角色是否说话不决定其是否需要形象参考；开场可见、后续才可见、画外发声与仅被提及分别核对，连同形象版本、真实资产、附件编号和容量一起读回验证。

编辑器使用具名引用时，再执行[具名引用到实际附件的闭环](references/prompt-plan.md#具名引用到实际附件的闭环)。显示为引用标签、有绑定记录和实际随请求提交是三件事；以当前版本和当前选择编译预览核对，不能用旧制作文档覆盖后来已修好的绑定。

## 分段与摄影

用户要求全量审查或重排时，先用 `ai-video-directing` 从事件链重新决定边界，再编写本技能的正文。第三方提示词技能的“不改分镜边界”是其阶段职责，不是冻结用户旧方案的理由；用户已授权的合并、拆分与剧本修订在导演阶段完成。不沿用旧段数作目标，不靠拼接旧正文实现合并。

一段是一次生成，可含多个摄影镜头；不跨集。模型容量为4–30秒，默认智能时长 `-1`；具体交付规格服从项目，用户手动时长保留。先判断对白、动作与反应能否自然完成，超载时按动作落定、交接完成或人物选择拆段，不删台词、不统一加速、不用30秒倒推逐秒时间轴。

镜头小标题、剧情概括与戏剧职责只留制作信息，不编入首帧或视频提交正文。多镜正文可用“镜头1：具体画面……”分隔，不写“镜头1｜概括标题：……”。删除标题前核对其中的必要事件、对象和时点是否已在具体描述中表达；缺失时补进对应动作，不丢失剧情。镜头编号、参考职责、光线及必要连续性标签仍可保留，不把清理标题扩大成删除有效指令。

逐镜正文用短句交代时间与地点，随后直接进入镜头1，不另设开场戏。按 `ai-video-directing` 的“场景说明、首帧与镜头正文的分工”，详细静态构图留在首帧计划，影响动作的起始前提写入相关镜头；未制作的首帧不能当作已提交信息。每个摄影镜头明确景别机位、观看对象、一个主要运动及终点、动作和接收反应；切镜交代信息或动作动机。简单事件可以一个自然段完成，不强迫填模板。保留原文明确的事件时点与短暂停顿，提示词不保证帧级控制。

逐镜整理时执行 `ai-video-directing` 的“摄影在前的自然段结构”：每镜先写景别、机位角度、固定或有对象与终点的运镜，再按时间顺序写具体动作、视线、人物情绪和原对白。将散落在后文的摄影说明重新安置，清除重复动作；旧句中混有的交接、避让、衣物变化不可随摄影前缀删除。场景光线集中说明，无须每镜重复焦段、强配运动或编造秒数。正文留镜头编号，概括标题仍只在制作栏。

检查刀剑与身体的相对方向时，以动作意图和实际运动平面消歧：明确轴线、刃尖、旁侧间隙及接触部位，不用“未伤”掩盖本会穿过手腕的路线。首帧、落定状态和后续拔刀分别成立；只需平面投影平行时写明视角，不虚构精确角度或实拍安全保证。

动作写到施力方、路线、接触点、受力变化与余波；左右手、道具持有人、视线、衣物和伤势连续。官方的小幅连续动作建议用于降低不必要的复杂度，不能把剧本必需攻防改成静止对望。减少同段并发变化，为高风险效果保留可独立重做的边界。

多人接触与机关施力按自定义导演技能的[肢体归属与动态取景专项](../ai-video-directing/references/rehearsal-and-resegmentation.md#肢体归属与动态取景专项)编译：分别点明易混淆的动作主语、施力肢体与受作用部位，按接稳、移交、撤离追踪控制；检查蹲起、腾手等必要可达过程，再核对动作起点、接触变化和落点是否在取景内。先区分必须同框、可顺序显露和前镜已建立的信息，选择放宽取景、有明确终点的跟移或保留近景；不能靠长修饰语猜手腕归属，也不能只改景别名称。修正同步首帧计划及起止字段；已有真实首帧须按实图核对，不因改文自动替换或重做。

表演写进实际镜头：可见触发、目光对象、一个关键表情／身体反应、随后选择与发话对象。把“理解、震惊、想逃”落实为可拍行为，不写读心说明；不让每个演员同时反应，不用形容词堆叠代替表演。多人或多道具镜头用稳定人名和具体物件消歧，避免连续“他／另一只／那边”。先建立空间再写“同侧”，演员左右手与画面方向分开。

精炼时按[表演落地与最终提交去重](../ai-video-directing/references/rehearsal-and-resegmentation.md#表演落地与最终提交去重)区分可见表演、声音语气和心理解释。“轻蔑、平静”等不是禁词；保留原指定语气，已有动作能表达的意图不再总结，也不机械增加皱眉、咬牙。公共图像／声音规则在最终提交正文只集中一处，具名素材及真实编号映射不随去重删除；应用会自动追加时，不在创作正文重复，脱离应用交付完整文本时须补齐。不得用运行时宽泛删词规则改写用户自由文本。

合并后重新组织镜头、对白和参考映射，检查说话人数、音频总时长、开场适配及复杂变化。对白只出现一次，直接写在它开始的镜头中；若跨镜说明持续到哪里，不同时提供另一份重复台词。去掉与画面无关的审查解释、冗长排除项及重复起终状态；必要的状态限制保留为正向可见事实。提示词长度没有通用成功阈值，应减少信息竞争与歧义，而非删关键过程凑字符数。

精炼与全剧重写采用 `ai-video-directing` 的“画面重点与正文精炼”：先确定每个摄影镜头的观看对象、人物意图与关系变化，再编译成自然画面描述。普通动作简写，危险接触与支撑交接保留细节；显式摄影切换不新增生成任务。参考职责集中、光线按同场统一，首帧只呈现静态起点。不能把减字、增加镜头编号或逐镜写焦段当作完成精炼；源稿、镜头正文、首帧、对白映射须一同核对。

已有真实选用首帧时，执行[已选首帧后的动作正文](../ai-video-directing/references/rehearsal-and-resegmentation.md#已选首帧后的动作正文)：摄影之后直接写动作，不在镜头1重述站位、衣装和握姿清单；必要方向与接触关系写在动作处，袖口等连续性集中一次。素材编号和音色仍须按真实附件编译，联合参考不等于逐像素锁定首帧。

同集同场连续段，优先预览上一段已选原片的真实干净尾帧，核对实际状态后显式选为下一段开场参考；这不是上传上一段视频进行延长。没有真实尾帧时保留待准备状态。集首、转场或不适合承接时使用独立起点。

编译状态约束时采用 `ai-video-directing` 的“状态约束的生效阶段”：开场只写当下，整段连续性只写贯穿全段的事实，阶段条件写在对应接触或变化之后，结束状态不反写成全程姿态。例如刀尚在手中时，不能用“刀始终留门框”；应先写脱手入木，再写入木后的状态。检查参考图是否提前带入末态、第一镜能否从首帧开始、相邻段是否重复已完成动作。已在镜头内写清的交接和落定不重复追加段尾动作摘要。保留承重和情绪停顿，不以“持续运动”抵消互相矛盾的指令。

## 声音与正文边界

对白逐字对应当前源稿（包括用户授权后的修订），明确说话人、指定语言和语气。可用 `角色以指定语气说{原文}`、`<动作音效>`、`（配乐）` 区分声音；不因采用符号就新增配乐或声源。角色音色引用实际绑定音频并冻结版本；最多10段、每段2–30秒且合计不超过30秒，缺失或超限须重新准备，不能静默换声或截短后沿用旧确认。

画幅、分辨率、总时长、模型、音频开关、价格和后期说明留在参数／制作信息。只有用户或项目已要求时才加无画外字幕等约束；该正文要求不转成虚构的模型 API 参数。字幕交由外部剪辑或另行委托时，保存原文对白、说话人与镜头映射，不在生成界面、请求或数据库加入字幕后期配置，也不自动识别或烧录。日后受托制作精确字幕时才按实际音轨核对，不贴未说出的台词、不预编时间码。

用户只要改写时只返回一份正文；用户要制作方案时交付制作信息、真实有序附件、首帧提示词、视频正文、参数和未解决项。保存到 Loop 时使用正常认证和修订检查，读回正文、附件顺序与参数，不自动提交生成。

## 样片与升片

新视频默认480P Draft、智能时长 `-1`。只有用户明确要求升片才准备1080P正式视频。样片和升片分别计次、确认和计费；升片引用原样片任务ID，继承其真实提示词、附件、种子、声音、时长与画幅，不能把当前改写正文静默带入升片。改写内容应生成新样片并重新逐次确认。有效期从供应商创建时间计算，过期不能自动重投。

参考生成明确 `reference`；编辑明确唯一母版、修改范围和保持项，锁定 `ratio=adaptive,duration=-1`；向前／向后延长明确边界动作、声音及方向，锁定 `ratio=adaptive`。参数留在制作信息，正文只表达事件和素材职责。

## 提交和复核

本技能不默认调用生成服务。每次真实视频新增或重做，先从 Loop 读取已生成／总数、当前段与集号、本段实际调用次数、本次尝试序号和未生成数；展示冻结角色、音色版本、真实附件、规格、预计费用与价格依据，再等用户对本段本次明确确认。确认变化需重审；不批量沿用授权，不自动重投结果不明的请求。

输出前逐项核对人物、原文对白、因果、动作容量、起止状态、附件职责与编号。生成后保存原片并完整观看，审查身份、动作、声音和连续性；技术成功不等于验收。报告官方尾帧是否返回并保存；有原片但无官方尾帧时本地提帧并标注来源，无原片则说明无帧可提。费用分预计与返回用量按冻结单价测算，未知不能记零，实际扣款以供应商账单为准，不增加手工实付登记。

文本修订收尾同时执行 `ai-video-directing` 的“对白、画面与跨字段复核”，尤其检查闭门后的画外声、跨镜台词是否仍在发声，以及光线或参考说明是否重新引入已移走的动作。程序校验不能替代这些语义检查。

刀剑、工具、门槽和转轮的方向要求执行[刀向与接触方向的阶段约束](../ai-video-directing/references/rehearsal-and-resegmentation.md#刀向与接触方向的阶段约束)：固定视角才用观众左右，切镜后用物理参照；明确接触面、承托和生效阶段，必要转向须在脱离接触后发生。不能用全程禁止反转覆盖正常动作或机关回弹。

机位、首帧依赖、配角和声音一起复核时执行[最少初态与可读取景](../ai-video-directing/references/rehearsal-and-resegmentation.md#最少初态与可读取景)：示例先核对事实；必要初态嵌入动作，取景区分主体与已建立的静止物；切镜只接关键状态，音色与表演职责分开。
