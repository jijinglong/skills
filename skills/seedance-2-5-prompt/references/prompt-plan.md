# 制作方案与示例

完整方案每段分别记录：来源与集号、生成段编号、戏剧目标、预计容量、起止状态、动作／对白风险、真实有序附件及其版本、首帧计划、视频正文、执行参数、费用假设和待准备项。不把这些栏目全塞入可提交正文。

先做原文覆盖检查，再按完整事件分段；一句话和一个切镜都不自动等于一个生成任务。按4–30秒模型容量重新排演对白、动作、交接与反应；自然成立的同场回合可以合并，超载时按选择或结果落点拆分。30秒是上限，不用旧段秒数相加代替重新编排。

## 可见角色与素材覆盖复核

逐镜建立以下职责，再汇总到生成段；不能只从对白名单或第一镜提取角色。

| 实际职责 | 核对范围 |
| --- | --- |
| 首帧可见的具名角色 | 首帧制作所需形象、站位和当下衣物状态，以及视频中的身份延续 |
| 后续镜头才可见的具名角色 | 视频参考覆盖；不为补绑定强行塞入开场 |
| 只在画外发声的角色 | 实际声音绑定、声源方位和听者反应；不自动增加人物出镜 |
| 仅被提及或名字出现在道具上 | 不据此新增人物画面或音色附件 |

在已采用角色参考的工作流中，沿“角色 → 当前形象 → 资源 → 实际资产”逐项核验，包含沉默的在场者与反应镜头中的人物。匿名背景群众不机械要求独立角色资产；纯文生不虚构图片引用，严格首帧路由不擅自混入联合参考。

称呼检查不能只匹配姓名：将“父亲、同伴、护送者、无甲者”等别称和群体称呼结合前后镜解析到实际人物，再判断谁在画内。分别比较“首帧可见人物 ↔ 首帧附件”和“全段可见人物 ↔ 视频身份引用”；视频里已有角色绑定不代表首帧制作已覆盖。已离场者、地点名带出的人名和纯画外称呼不算可见角色，身份无法确定时先标待核对，不凭空补人。

优先复用已核验且状态相符的真实图片，新采用的候选图先预览。开场尚未破损或卷袖时，不能因名称像战斗造型就采用已破损、已卷袖图片；衣物后来变化的阶段写回对应动作。缺少合适素材列待准备，不为补覆盖自动发起生成。 排除项也按当前阶段重新判断：例如上铐前排除设定图中的手铐，上铐后保留剧情规定的铐法、只排除设定图错误的链长或手位；不能把前段“无手铐”的排除项复制到后段。优先选择相符素材，确需借用时只采用可分离的身份特征，显著冲突列入待准备项，不能把文字排除视作图像已修正。

补绑定时保留仍有效附件的相对顺序，新增或移除后分别重算首帧制作与视频清单的图片编号，并独立核对声音编号。按当前模型目录重新检查图片、音频及全部模态容量；超限时重新安排参考或生成边界，不因角色没有台词就静默漏掉其身份要求。

保存后对照逐镜人物职责读回实际角色绑定、形象版本、资产、正文编号与参数；制作文档也从同一当前版本更新。只比正文、只数附件或只验文件哈希不能证明角色覆盖正确，无法查看的素材须保留未核验说明。

## 具名引用到实际附件的闭环

先重新读取执行端的当前正文、修订号、角色形象选择和引用绑定，再与本地计划比较。上次报告的失效引用可能已经修复：保留当前有效修改，分别报告“本次修复”与“复核已有修复”，不要把旧告警当成当前事实，也不要回写旧正文抹掉新绑定。

沿“正文具名标记 → 绑定角色与资产 → 当前镜头所选形象资源 → 实际选用附件 → 编译后的图片／音频槽位”逐项核对。名字正确但没有绑定、绑定指向旧造型、资源存在但未选入本次请求、音色身份与真实音频附件混淆，都会断开这一链。角色库中有图、首帧制作使用过图或正文提过人物，都不等于视频请求已经携带该图。沉默角色的身份参考也按实际出镜职责检查。

能复用执行端的默认选择与纯编译函数时，使用当前附件做无生成的编译预览，检查未解析标记、角色对应、顺序和模型目录容量。不能为了清零告警虚构资产、只去掉标记却丢掉身份要求，或调用付费生成来验证绑定。缺少实际开场时，预览须明确尚缺开场，不能用占位ID伪装冻结提交；选定开场后重新计算后续图片编号。

正常认证和修订检查保存后，读回源稿、正文、绑定、形象选择与参数，刷新制作文档和提交预览。即使只改变引用、没有改动作，也要使预览对应当前版本。引用编译通过只证明映射可解析，不代表已经审看真实媒体、音色已重新审听或获得生成授权。

## 交接示例

以下是虚构交接示例，不能当作已审看素材或项目原文。假设图片1已核对为旧书店开场，林舟在柜台内、顾言在外，信封在柜台上；音频1、2分别是已绑定两人的真实音色，合计6秒。

首帧计划只画动作前状态：同侧平视中景，两人隔柜台相对，信封仍放在桌面；不提前画成已经交付。真实首帧未制作时标为计划，不能在视频附件清单填假ID。

联合参考正文直接进入正式镜头，不另外重述一段开场。以下已存在图片1；缺图时把必要位置与持物写入镜头，而不是假称有图。

联合参考正文：

```text
场景：日间，旧书店柜台。

图片1提供人物站位和柜台布局。林舟的声音参考音频1，顾言的声音参考音频2，音频中的试听内容不作为对白。

镜头1：沿柜台侧面的平视中景，林舟看向柜台外的顾言，说{给你。}林舟用右手拿起柜台上唯一的信封，伸向顾言；顾言看向信封并抬起左手。

镜头2：在顾言接触信封时同轴切近两人的手。顾言左手接稳后林舟松开右手，顾言把信封收向自己身前，说{谢谢。}<纸张轻响>随后回到两人关系中景，信封只在顾言左手，两人仍隔柜台相对。
```

参数单列：Seedance 2.5、480p Draft、`duration: -1`、用户所选比例、有声、实际音频附件。该示例不能改称严格首帧模式。只用一张严格首帧且无参考音频／角色图时，正文从画面当前状态开始，不虚构音频标签。

独立文生正文示例：

```text
旧书店柜台内的林舟与柜台外的顾言相对，柜台上放着一只信封。平视中景，林舟用右手拿起信封递向顾言，顾言左手接稳后林舟松手。镜头随交接缓慢推近信封，结束时信封只在顾言左手，两人的柜台内外关系保持不变。
```

校对情境：缺少图片时不生成图片引用；已有编号无法查看时原样保留并在制作信息说明未核验；四位发话人可以分别绑定四段真实音频，核对每段2–30秒、总计不超过30秒及全部模态容量，重新计算合并后的附件顺序与音色映射；尾帧缺失时不能声称已续接；仅字幕不准时先修后期。
