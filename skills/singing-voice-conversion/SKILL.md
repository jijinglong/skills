# 歌声换音色

先确定用户需要新人声分轨、完整混音还是换声后的 MV。读取作品入口和上一版剪辑记录，找到原唱时间基准、现有分轨、采用的成片和已有转换结果。已有换声干声可直接进入对齐。按作品目录保存采用的分轨和混音，最终成片另存新版本。在 Beat 中，原件留在 `sources/`，拆解得到的原始分轨留在 `analysis/`，采用的转换干声、混音与剪辑记录存入 `production/`，正式交付放 `exports/`，可重建的中间文件放 `scratch/`。

## 1. 准备干声、伴奏和时间基准

- 优先复用可用的主唱与伴奏分轨。只有完整混音时，先分离主唱和伴奏，按需保留环境声、音效与和声。试听主唱中的伴奏串音、重叠唱声、混响和回声，试听伴奏有无残留原唱。原混音用来对照响度和时间，不叠到新人声底下。
- 对照已采用成片、字幕和原唱确认时间零点。标记首句开口、换句、画面切点、闭口音和末句收尾。保留干声开始前的静默和尾音。使用 FFprobe 或等效工具核对时长、采样率、声道和起始时间。工具需要单声道时另导出保留原时序的单声道 WAV，试听下混有没有丢失人声。

## 2. 转换演唱音色

- 使用以原唱音频为输入的歌声转换模式。选用户指定、可使用且音域匹配的音色。只换音色时保留原调、原速、旋律和唱词。同一段连续演唱在服务容量允许时整段转换，保持声线和句间衔接。必须分段时记录原曲时码，选句间停顿并留出试听与拼接余量。
- 使用 Audimee 时读 [Audimee 操作与参数](references/audimee.md)。有账号登录、余额或导出格式问题时，先保留已完成的准备和当前任务状态。从可确认的阶段继续，提交结果不明时先查历史任务。
- 下载平台实际提供的最高可用质量。保留下载原件；MP3 可以解码成 WAV 供编辑，记录原格式。仅使用用户授权处理的素材与音色。涉及对外发布时，按发行用途核对歌曲、声音模型和账号方案允许的使用范围。

## 3. 对齐原唱

- 将原唱与新人声以相同采样率放在同一时间轴。先检查整体偏移，再比分布在开头、中段和末尾的发声时点。结合试听、波形或响度包络定位，复核开口、擦音、闭口、停顿和拖音。音色变化会改变波形形状，按可听音节和画面口型确认局部对齐。
- 各处偏差一致时，对新人声整体移位，分别用裁掉前置余量或补静默校正迟到或早到。只有个别字偏移时，局部移动或保留音高的微调，用极短淡化处理接缝。累计漂移先核对源版本、导出延迟和时间基准。整条拉伸会改变口型关系，按实际误差决定是否需要。校正后复听快速歌词、重复音节和画面切点。

## 4. 回混伴奏与交付

- 对齐的新人声与同一时间基准的伴奏回混，按原版或用户要求调平衡。另有应保留的音效、环境声或和声时，确认已在伴奏里或按轨加入。监听重影、残留原唱、爆音、切点断裂和结尾截尾；测量响度和真峰，按当前作品规范留余量。以视频实际帧长为时间基准裁齐或补足最后的静默，避免用显示界面的四舍五入时长裁剪。
- 已有成片且画面锁定时，用剪辑软件或 FFmpeg 替换旧音轨。选择能保留已剪画面、原帧率与字幕的方式。烧录字幕随画面保留，独立字幕轨和需要保留的其他流要在导出时显式映射。见 [锁画面的 FFmpeg 封装与验证](references/remux.md)。
- 用最终文件复核开头、各发声和画面关键点、结尾、字幕、音视频时长、画幅和帧率。交付采用的干声、混音或新成片，按请求提供对应项目入口。记录输入版本、音色、参数、整体或局部对齐量、混音变动和最终路径；在试听或回放前将口型状态标为待核。
