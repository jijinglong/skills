# Audimee 操作与参数

1. 打开 [Convert Vocals](https://audimee.com/create)。在 **Switch voice** 中按用户要求筛选，试听目标音色并查看核心音域。选与原唱音域和发声质感相配的预设。自定义音色沿用项目已有且可用的模型。
2. 在 **Input** 上传整段已分离的干声。优先使用无混响、无伴奏、只有一个主唱的录音。已有干净分轨时保持隔离开关关闭；输入仍含伴奏、和声、混响或噪声时才启用对应选项。单独使用隔离功能时查实际额度。 [Audimee 隔离功能](https://audimee.com/isolate)
3. 保留原调与演唱方式时，**Pitch shift** 用 `0` 半音，**Quick tuning** 保持关闭，保留原有颤音。**Conversion strength** 在非英语歌声可从 `30%` 起，按实际咬字与音色差异调整。咬字发糊、尾音颤动或出现合成杂音时，先核对干声与目标音域，再调整转换强度。 [Audimee 转换设置](https://audimee.com/create) · [输入音质与换声问题](https://audimee.com/faq/troubleshooting/conversion-issues)
4. 核对当前账号可用音色、文件限制、转换额度和下载选项。按用户对上传与转换的授权提交 **Convert**。需要登录时停在已有状态并说明待完成的一步；能继续本地工作时先准备分轨和对齐基准。提交后从 **Output** 或任务历史确认状态，完成后试听并下载采用结果。导出质量和商用许可按当前方案核对。 [Audimee 方案与格式](https://audimee.com/pricing)

例如，要给已按日语原唱对好口型的短 MV 换成另一种女声，先用整段原曲干声一次转换。维持 `0` 半音并关闭自动修音，核对快速音节和连续重复词的咬字。只有新人声实际对齐后，才把它混回原伴奏并应用到锁定的成片。
